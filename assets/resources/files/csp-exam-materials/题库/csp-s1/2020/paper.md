### 第 1 题

<!-- qid: csp-s1-2020-001 | type: single_choice | score: 2 | answer: C | tags: feat:formula,topic:number -->

请选出以下最大的数（ ）

- A. $(550)_{10}$
- B. $(777)_{8}$
- C. $2^{10}$
- D. $(22F)_{16}$

> **题解**
> 答案：C
> 解释：把四个数都化成十进制再比较：(550)₁₀ 就是 550，(777)₈ = 7 × 64 + 7 × 8 + 7 = 511，2¹⁰ = 1024，(22F)₁₆ = 2 × 256 + 2 × 16 + 15 = 559。最大的是 1024，对应 C 项。B 项八进制的 777 看着位数最多，实际只有 511，是最常见的失分点；A 项 550 与 D 项 559 也都小于 1024。

### 第 3 题

<!-- qid: csp-s1-2020-003 | type: single_choice | score: 2 | answer: B | tags: topic:basics -->

现有一段 8 分钟的视频文件，它的播放速度是每秒 24 帧图像，每帧图像是一幅分辨率为 2048×1024 像素的 32 位真彩色图像。请问要存储这段原始无压缩视频，需要多大的存储空间？（ ）。

- A. 30G
- B. 90G
- C. 150G
- D. 450G

> **题解**
> 答案：B
> 解释：先算一帧：2048 × 1024 个像素、每个 32 位即 4 字节，一帧是 2048 × 1024 × 4 字节 = 8 MiB。再算总帧数：8 分钟 × 60 秒 × 24 帧 = 11520 帧。两者相乘得 11520 × 8 MiB = 92160 MiB，正好是 90 GiB，选 B。A 项 30G 相当于把每秒帧数当成了 8，C、D 两项与任何合理的单位换算都对不上。

### 第 4 题

<!-- qid: csp-s1-2020-004 | type: single_choice | score: 2 | answer: B | tags: topic:ds -->

今有一空栈 S，对下列待进栈的数据元素序列 a,b,c,d,e,f 依次进行：进栈，进栈，出栈，进栈，进栈，出栈的操作，则此操作完成后，栈底元素为（ ）。

- A. b
- B. a
- C. d
- D. c

> **题解**
> 答案：B
> 解释：按操作顺序模拟，把栈底写在左：进 a 得 a；进 b 得 a、b；出栈弹掉 b 得 a；进 c 得 a、c；进 d 得 a、c、d；再出栈弹掉 d，最后栈内只剩 a。栈底始终是最先进入的 a，选 B。C 项 d、D 项 c 都曾处在栈顶，本题问的是栈底——栈是后进先出，唯一不会变的就是第一个进去的元素。

### 第 5 题

<!-- qid: csp-s1-2020-005 | type: single_choice | score: 2 | answer: D | tags: feat:formula,topic:ds -->

将（2，7，10，18）分别存储到某个地址区间为 0~10 的哈希表中，如果哈希函数 $h(x) =$（ ），将**不会**产生冲突，其中 $a \mod b$ 表示 $a$ 除以 $b$ 的余数。

- A. $x^2 \mod 11$
- B. $2x \mod 11$
- C. $x \mod 11$
- D. $[x/2] \mod 11$，其中 $[x/2]$ 表示 $x/2$ 下取整

### 第 6 题

<!-- qid: csp-s1-2020-006 | type: single_choice | score: 2 | answer: B | tags: topic:greedy -->

下列哪些问题**不能**用贪心法精确求解？（ ）

- A. 霍夫曼编码问题
- B. 0-1 背包问题
- C. 最小生成树问题
- D. 单源最短路径问题

> **题解**
> 答案：B
> 解释：0-1 背包的每件物品只能整件拿或不拿，按单位价值从高到低贪心会「先拿的一件占掉了空间、后面更好的组合进不来」。反例：容量 10，一件重量 10、价值 60；另一件重量 6、价值 50。贪心先取单位价值高的后者（6 ≤ 10），剩 4 装不下前者，得 50；最优是只拿前者得 60。所以 0-1 背包必须用动态规划，选 B。A 项霍夫曼编码、C 项最小生成树（Kruskal、Prim）、D 项单源最短路（Dijkstra）都能用贪心精确求解。

### 第 7 题

<!-- qid: csp-s1-2020-007 | type: single_choice | score: 2 | answer: A | tags: feat:formula,topic:complexity,topic:graph -->

具有 $n$ 个顶点，$e$ 条边的图采用邻接表存储结构，进行深度优先遍历运算的时间复杂度为（ ）。

- A. $\Theta(n+e)$
- B. $\Theta(n^2)$
- C. $\Theta(e^2)$
- D. $\Theta(n)$

> **题解**
> 答案：A
> 解释：邻接表存储时，深度优先遍历每个顶点最多被访问一次，每条边最多被检查两次（无向图）或一次（有向图），代价正比于顶点数与边数之和，即 Θ(n + e)，选 A。B 项 Θ(n²) 是邻接矩阵存储、每次都要扫一整行才能找齐邻接点的代价；C 项 Θ(e²) 与边数平方无关；D 项 Θ(n) 漏掉了每条边也都要处理。

### 第 8 题

<!-- qid: csp-s1-2020-008 | type: single_choice | score: 2 | answer: A | tags: topic:graph -->

二分图是指能将顶点划分成两个部分，每一部分内的顶点间没有边相连的简单无向图。那么，24 个顶点的二分图**至多**有（ ）条边。

- A. 144
- B. 100
- C. 48
- D. 122

> **题解**
> 答案：A
> 解释：二分图要求每条边的两个端点分属两侧。设一侧有 k 个顶点、另一侧有 24 − k 个，边数至多是 k(24 − k)，这个二次式在 k = 12 时取到最大值 12 × 12 = 144，选 A。B 项 100、C 项 48、D 项 122 都不是 k(24 − k) 能取到的值（把 k 代遍 0 到 24 也只会出现 0、23、44、63、80、95、108、119、128、135、140、143、144 这些数）。

### 第 10 题

<!-- qid: csp-s1-2020-010 | type: single_choice | score: 2 | answer: C | tags: feat:formula,topic:number -->

一个班学生分组做游戏，如果每组三人就多两人，每组五人就多三人，每组七人就多四人，问这个班的学生人数 $n$ 在以下哪个区间？已知 $n<60$。（ ）。

- A. $30<n<40$
- B. $40<n<50$
- C. $50<n<60$
- D. $20<n<30$

> **题解**
> 答案：C
> 解释：题意即 n ≡ 2 (mod 3)、n ≡ 3 (mod 5)、n ≡ 4 (mod 7)。同时满足前两条的数每 15 一个，60 以内是 8、23、38、53；逐个验第三条：8、23、38 除以 7 的余数分别是 1、2、3，只有 53 的余数是 4。所以 n = 53，落在 50 < n < 60，选 C。A 项 30 到 40 区间、B 项 40 到 50 区间、D 项 20 到 30 区间里没有任何一个数同时满足三个余数条件。

### 第 11 题

<!-- qid: csp-s1-2020-011 | type: single_choice | score: 2 | answer: C | tags: feat:formula,topic:math -->

小明想通过走楼梯来锻炼身体，假设从第 1 层走到第 2 层消耗 10 卡热量，接着从第 2 层走到第 3 层消耗 20 卡热量，再从第 3 层走到第 4 层消耗 30 卡热量，依此类推，从第 $k$ 层走到第 $k+1$ 层消耗 $10k$ 卡热量（$k>1$）。如果小明想从 1 层开始，通过连续向上爬楼梯消耗 **1000** 卡热量，**至少**要爬到第几层楼？（ ）。

- A. 14
- B. 16
- C. 15
- D. 13

> **题解**
> 答案：C
> 解释：从第 1 层爬到第 N 层，消耗是 10 × (1 + 2 + … + (N − 1)) = 5N(N − 1)。代 N = 14 得 5 × 14 × 13 = 910 < 1000，代 N = 15 得 5 × 15 × 14 = 1050 ≥ 1000，所以至少要爬到第 15 层，选 C。A 项 14 层的 910 卡还差 90 卡达不到 1000；B 项 16 层虽然也够，但不是最小的。

### 第 12 题

<!-- qid: csp-s1-2020-012 | type: single_choice | score: 2 | answer: D | tags: feat:formula,topic:ds -->

表达式 $a*(b+c)-d$ 的后缀表达形式为（ ）。

- A. abc*+d-
- B. -+*abcd
- C. abcd*+-
- D. abc+*d-

> **题解**
> 答案：D
> 解释：按「先括号、再乘法、最后减法」把表达式写成后缀：b c + 表示 b 与 c 相加，a b c + * 表示用 a 去乘前面算出的结果，整个表达式就是 a b c + * d −，选 D。A 项 abc*+d− 让 b、c 先相乘，丢掉了括号；B 项 -+*abcd 是整个式子倒过来的前缀形式；C 项把乘号放到了加号之后。

### 第 14 题

<!-- qid: csp-s1-2020-014 | type: single_choice | score: 2 | answer: D | tags: feat:formula,topic:complexity,topic:graph -->

对一个 $n$ 个顶点、$m$ 条边的带权有向简单图用 Dijkstra 算法计算单源最短路时，如果不使用堆或其它优先队列进行优化，则其时间复杂度为（ ）。

> 答案：D

## 二、阅读程序

> 程序输入不超过数组或字符串定义的范围；判断题正确填√，错误填×；除特殊说明外，判断题 1.5 分，选择题 3 分，共计 40 分。

### (1)

<!-- group: 阅读程序(1) -->

```cpp
 01  #include <iostream>
 02  using namespace std;
 03
 04  int n;
 05  int d[1000];
 06
 07  int main() {
 08      cin >> n;
 09      for (int i = 0; i < n; ++i)
 10          cin >> d[i];
 11      int ans = -1;
 12      for (int i = 0; i < n; ++i)
 13          for (int j = 0; j < n; ++j)
 14              if (d[i] < d[j])
 15                  ans = max(ans, d[i] + d[j] - (d[i] & d[j]));
 16      cout << ans;
 17      return 0;
 18  }
```

假设输入的 $n$ 和 `d[i]` 都是不超过 10000 的正整数，完成下面的判断题和单选题：

> **程序说明**
> 这段程序先读入 n 和 n 个整数 `d[0]`…`d[n-1]`，再枚举所有满足 `d[i] < d[j]` 的下标对，把 `d[i] + d[j] - (d[i] & d[j])` 的最大值输出；如果一个这样的下标对都没有（例如 n 为 1，或所有 d 都相同），就输出初值 `-1`。关键一步是把那个表达式看出来：由 a + b = (a & b) + (a | b) 可知它恰好等于 `d[i] | d[j]`，所以程序求的是「任取两个下标、按位或之后能得到的最大的数」，是「或」而不是「和」。理解这一组要抓住两点：一是内层判断用的是严格小于，两个相等的元素不会被配对，`ans` 可能一直停在 `-1`；二是数组只开到 `int d[1000]`，所以输入的 n 必须小于 1000，否则读入时就会越界。

#### 判断题

##### 第 16 题

<!-- qid: csp-s1-2020-016 | type: true_false | score: 1.5 | answer: F | tags: feat:formula,topic:lang -->

$n$ **必须**小于 1000，否则程序**可能**会发生运行错误。（ ）

> **题解**
> 答案：×
> 解释：数组定义是 `int d[1000]`，下标范围 0 到 999，所以 n = 1000 时读入的正好是 `d[0]` 到 `d[999]`，程序完全正常。实跑验证：n = 999 与 n = 1000 两组输入都正常退出（退出码 0），输出与「把缓冲区放大到 100000、其余一字不动」的对照版逐位相同（都是 16383）；只有 n = 1001 起原版才写出界、输出变成 2147483645。可见「必须小于 1000」把 n = 1000 这个合法取值也排除掉了，主张不成立，填 ×。

##### 第 17 题

<!-- qid: csp-s1-2020-017 | type: true_false | score: 1.5 | answer: F | tags: topic:sim -->

输出**一定**大于等于 0。（ ）

> **题解**
> 答案：×
> 解释：`ans` 的初值是 −1：只要找不到任何一对满足 `d[i] < d[j]` 的下标，它就停在 −1 上，而 −1 小于 0。实跑反例：输入 n = 1、d = `5`，输出 `-1`；输入 n = 3、d = `7 7 7`，元素两两相等、不构成严格小于，同样输出 `-1`。故主张不成立，填 ×。

##### 第 18 题

<!-- qid: csp-s1-2020-018 | type: true_false | score: 1.5 | answer: T | tags: feat:lineref,topic:sim -->

若将第 13 行的 `j = 0` 改为 `j = i + 1`，程序输出**可能**会改变。（ ）

> **题解**
> 答案：√
> 解释：原程序枚举所有有序对 (i, j)，只要 `d[i] < d[j]` 就参与计算；改成 j = i + 1 以后只剩 j 大于 i 的那些对，形如「小值在后、大值在前」的配对就再也取不到了。实跑反例：输入 n = 3、d = `18 2 3`，原程序输出 19（取的是下标 1 与 0、值 2|18 = 19），改成 j = i + 1 后输出 3；3000 组随机输入里有 930 组输出不同。故主张成立，填 √。

##### 第 19 题

<!-- qid: csp-s1-2020-019 | type: true_false | score: 1.5 | answer: T | tags: feat:lineref,topic:sim -->

将第 14 行的 `d[i] < d[j]` 改为 `d[i] != d[j]`，程序输出**不会**改变。（ ）

> **题解**
> 答案：√
> 解释：两个条件都只排除「两数相等」的情形（原式要求严格小于，改后要求不相等），而 `d[i] + d[j] - (d[i] & d[j])` 对 i、j 是对称的，所以取值不同的每一对下标两个版本都会算进去，最大值不变。实跑验证：3000 组随机输入（取值 1 到 30、含大量重复）两版输出逐个相同，0 组不同。故主张成立，填 √。

#### 单选题

##### 第 20 题

<!-- qid: csp-s1-2020-020 | type: single_choice | score: 3 | answer: C | tags: feat:formula,topic:bit,topic:sim -->

若输入 $n$ 为 100，且输出为 127，则输入的 `d[i]` 中**不可能**有（ ）。

- A. 127
- B. 126
- C. 128
- D. 125

> **题解**
> 答案：C
> 解释：输出 127 说明参与的那一对按位或的结果是 127 = 1111111₂，只占低 7 位。若 d 里有 128 = 10000000₂，只要它和任何一个不同的数配对，结果就会带上第 7 位、至少是 128；若 d 里全是 128，则不存在 `d[i] < d[j]` 的下标对，输出初值 −1。两条路都得不到 127，故 128 不可能出现，选 C。A 项 127、B 项 126、D 项 125 都可能：d = `127 125` 得 127|125 = 127，d = `127 126` 得 126|127 = 127，都合法。

##### 第 21 题

<!-- qid: csp-s1-2020-021 | type: single_choice | score: 3 | answer: C | tags: topic:bit,topic:sim -->

若输出的数大于 0，则下面说法**正确**的是（ ）。

- A. 若输出为偶数，则输入的 `d[i]` 中**最多**有两个偶数
- B. 若输出为奇数，则输入的 `d[i]` 中**至少**有两个奇数

```cpp
 01  #include <iostream>
 02  #include <queue>
 03  using namespace std;
 04
 05  const int maxl = 2000000000;
 06
 07  class Map {
 08      struct item {
 09          string key; int value;
 10      } d[maxl];
 11      int cnt;
 12  public:
 13      int find(string x) {
 14          for (int i = 0; i < cnt; ++i)
 15              if (d[i].key == x)
 16                  return d[i].value;
 17          return -1;
 18      }
 19      static int end() { return -1; }
 20      void insert(string k, int v) {
 21          d[cnt].key = k; d[cnt++].value = v;
 22      }
 23  } s[2];
 24
 25  class Queue {
 26      string q[maxl];
 27      int head, tail;
 28  public:
 29      void pop() { ++head; }
 30      string front() { return q[head + 1]; }
 31      bool empty() { return head == tail; }
 32      void push(string x) { q[++tail] = x; }
 33  } q[2];
 34
 35  string st0, st1;
 36  int m;
 37
 38  string LtoR(string s, int L, int R) {
 39      string t = s;
 40      char tmp = t[L];
 41      for (int i = L; i < R; ++i)
 42          t[i] = t[i + 1];
 43      t[R] = tmp;
 44      return t;
 45  }
 46
 47  string RtoL(string s, int L, int R) {
 48      string t = s;
 49      char tmp = t[R];
 50      for (int i = R; i > L; --i)
 51          t[i] = t[i - 1];
 52      t[L] = tmp;
 53      return t;
 54  }
 55
 56  bool check(string st, int p, int step) {
 57      if (s[p].find(st) != s[p].end())
 58          return false;
 59      ++step;
 60      if (s[p ^ 1].find(st) == s[p].end()) {
 61          s[p].insert(st, step);
 62          q[p].push(st);
 63          return false;
 64      }
 65      cout << s[p ^ 1].find(st) + step << endl;
 66      return true;
 67  }
 68
 69  int main() {
 70      cin >> st0 >> st1;
 71      int len = st0.length();
 72      if (len != st1.length()) {
 73          cout << -1 << endl;
 74          return 0;
 75      }
 76      if (st0 == st1) {
 77          cout << 0 << endl;
 78          return 0;
 79      }
 80      cin >> m;
 81      s[0].insert(st0, 0); s[1].insert(st1, 0);
 82      q[0].push(st0); q[1].push(st1);
 83      for (int p = 0;
 84           !(q[0].empty() && q[1].empty());
 85           p ^= 1) {
 86          string st = q[p].front(); q[p].pop();
 87          int step = s[p].find(st);
 88          if ((p == 0 &&
 89               (check(LtoR(st, m, len - 1), p, step) ||
 90                check(RtoL(st, 0, m), p, step)))
 91              ||
 92              (p == 1 &&
 93               (check(LtoR(st, 0, m), p, step) ||
 94                check(RtoL(st, m, len - 1), p, step))))
 95              return 0;
 96      }
 97      cout << -1 << endl;
 98      return 0;
 99  }
```

> **程序说明**
> 这段程序在字符串上做最短步数搜索：读入两个字符串 `st0`、`st1` 和整数 m，输出把 `st0` 变成 `st1` 的最少操作次数；两者长度不同输出 `-1`，本来就相等输出 `0`，搜完仍无解也输出 `-1`。一次操作是把字符串的一段整体循环平移一位：`LtoR(s, L, R)` 把 `s[L]` 挪到 `R`、中间字符左移，`RtoL` 正好相反；两边各对下标 `0..m` 的前段和 `m..len-1` 的后段动手，方向互为逆操作，所以这是在同一张图上从两端同时搜。关键做法是双向 BFS：`s[0]`、`s[1]` 是两个手写的映射表（键是字符串、值是从各自起点走了几步），`q[0]`、`q[1]` 是两边各自的队列，外层循环用 `p ^= 1` 让两边轮流扩展；`check` 一旦发现新串已经在另一边的表里，就把两边的步数相加输出——这就是两边相遇的时刻。理解本组要记住：`check` 只把新串插入当前这一边的表，`Map::find` 找不到时返回 `-1`，`maxl` 只是容量上限，不参与算法逻辑。

> 解释：以当前元素 a 结尾的最优值 v 算出来以后，要把它写回表里、供将来的元素使用：按表的第一维「下一个位置的高 8 位」枚举 z，第二维写当前元素 a 的低 8 位 y，并把高 8 位之间的贡献加上去——z 与 x 分别是未来元素与当前元素的高 8 位，其差左移 8 位后正是高 8 位那部分的分值，即 `to_max(Max[z][y], v + w((x ^ z) << B))`，选 B。A 项把低 8 位写进了第一维、C 项用整个 a 去异或（量纲不对），D 项 `Max[x][z]` 把当前元素的高 8 位当成了未来的高 8 位、状态会写到错位置。实跑代入：⑤ 填 B 时 64 个用例全部正确；把 5 个空的全组合（共 1024 种）逐个代进程序，只有「①D ②B ③C ④A ⑤B」这一组在全部用例上与朴素解法一致。

### 第 1 题

<!-- qid: csp-s1-2022-001 | type: single_choice | score: 2 | answer: B | tags: topic:basics -->

在 Linux 系统终端中，用于切换工作目录的命令为（ ）。

- A. ls
- B. cd
- C. cp
- D. all

> **题解**
> 答案：B
> 解释：在 Linux 终端里 `cd` 是 change directory 的缩写，用来切换当前工作目录，选 B。A 项 `ls` 只列出目录内容，C 项 `cp` 复制文件，D 项 `all` 不是 Linux 命令（容易和 `ls -a`、`cd ..` 这类写法混淆），三者都不改变当前目录。

### 第 2 题

<!-- qid: csp-s1-2022-002 | type: single_choice | score: 2 | answer: A | tags: topic:basics -->

你同时用 time 命令和秒表为某个程序在单核 CPU 的运行计时。假如 time 命令的输出如下：

```
real    0m30.721s
user    0m24.579s
sys     0m6.123s
```

以下最接近秒表计时的时长为（ ）。

- A. 30s
- B. 24s
- C. 18s
- D. 6s

> **题解**
> 答案：A
> 解释：`time` 命令的第一行 `real` 是从命令开始到结束实际流逝的挂钟时间，`user` 与 `sys` 是分别花在用户态和内核态上的 CPU 时间。秒表量的正是挂钟时间，所以看 `real` 的 0m30.721s，约 30 秒，选 A。B 项 24s 只取了 `user`（CPU 时间），D 项 6s 只取了 `sys`，C 项 18s 两个都不是；单核 CPU 上 `user + sys = 24.579 + 6.123 = 30.702` 与 `real` 很接近只是巧合，不能用 CPU 时间去代替挂钟时间。

### 第 3 题

<!-- qid: csp-s1-2022-003 | type: single_choice | score: 2 | answer: D | tags: topic:ds -->

若元素 a、b、c、d、e、f 依次进栈，允许进栈、退栈操作交替进行，但不允许连续三次退栈操作，则不可能得到的出栈序列是（ ）。

- A. dcebfa
- B. cbdaef
- C. bcaefd
- D. afedcb

> **题解**
> 答案：D
> 解释：要判断哪个序列出不来，盯住「不许连续三次退栈」。D 项 `afedcb` 里 `a` 排在第一位，只能先把 `a` 入栈再立刻退栈；此后 `b`、`c`、`d`、`e`、`f` 必须都已入栈且 `f` 在栈顶，输出 `f` 之后接着还要输出 `e`、`d`、`c`、`b`，这就是连续 5 次退栈，违反规则，所以 D 不可能，选 D。A、B、C 都能排出来，例如 C：入 a、入 b、退 b、入 c、退 c、退 a、入 d、入 e、退 e、入 f、退 f、退 d，最多只连续退栈两次。穷举核对：6 个元素共有 132 种合法出栈序列，其中满足「无连续三次退栈」的有 51 种，`afedcb` 不在其中。

### 第 4 题

<!-- qid: csp-s1-2022-004 | type: single_choice | score: 2 | answer: C | tags: feat:formula,topic:complexity,topic:sort -->

考虑对 n 个数进行排序，以下最坏时间复杂度低于 $O(n^2)$ 的排序方法是（ ）。

- A. 插入排序
- B. 冒泡排序
- C. 归并排序
- D. 快速排序

> **题解**
> 答案：C
> 解释：归并排序在最好、最坏、平均情况下的时间复杂度都是 O(n log n)，低于 O(n²)，选 C。A 项插入排序、B 项冒泡排序最好时能到 O(n)，但最坏情况都是 O(n²)；D 项快速排序平均 O(n log n)，最坏（例如每次都取到极不均衡的划分）也是 O(n²)。题目问的是最坏情况，所以后三项都不满足「最坏低于 O(n²)」。

### 第 5 题

<!-- qid: csp-s1-2022-005 | type: single_choice | score: 2 | answer: A | tags: topic:sort -->

假设在基数排序过程中，受宇宙射线的影响，某项数据异变为一个完全不同的值。请问排序算法结束后，可能出现的最坏情况是（ ）。

- A. 移除受影响的数据后，最终序列是有序序列
- B. 移除受影响的数据后，最终序列是前后两个有序的子序列
- C. 移除受影响的数据后，最终序列是一个有序的子序列和一个基本无序的子序列
- D. 移除受影响的数据后，最终序列基本无序

> **题解**
> 答案：A
> 解释：基数排序逐位做的是稳定排序：某一位上的分配只决定元素本次落在哪个位置，关键字相等的元素保持原有先后。宇宙射线把某一个值改成完全不同的值以后，只有这一个元素会被分到别处，其余元素之间的相对次序并没有被打乱——把受影响的那一项拿出来删掉，剩下的序列仍然是有序序列，选 A。B、C、D 三项都要求「多个元素之间互相失序」，而基数排序不会打乱别的元素，所以都排除。

### 第 6 题

<!-- qid: csp-s1-2022-006 | type: single_choice | score: 2 | answer: B | tags: topic:basics -->

计算机系统用小端（Little Endian）和大端（Big Endian）来描述多字节数据的存储地址顺序模式，其中小端表示将低位字节数据存储在低地址的模式、大端表示将高位字节数据存储在低地址的模式。在小端模式的系统和大端模式的系统分别编译和运行以下 C++代码段表示的程序，将分别输出什么结果？（ ）

```
unsigned x = 0xDEADBEEF;
unsigned char *p = (unsigned char *)&x;
printf("%X", *p);
```

- A. EF、EF
- B. EF、DE
- C. DE、EF
- D. DE、DE

> **题解**
> 答案：B
> 解释：小端把低位字节放在低地址：`0xDEADBEEF` 的最低字节是 `0xEF`，它落在首地址上，`*p` 取到 `EF`；大端把高位字节放在低地址，首字节是最高位的 `0xDE`，`*p` 取到 `DE`。两种系统合起来是 EF、DE，选 B。A 项把大端也当成输出 `EF`（即认为两种模式没有区别），C 项把两者的输出写反，D 项认为都输出 `DE`。实机复核：在 x86（小端）上编译运行输出 `EF`，把同样四个字节按大端顺序摆好再取首字节得到 `DE`。

### 第 7 题

<!-- qid: csp-s1-2022-007 | type: single_choice | score: 2 | answer: C | tags: topic:tree -->

一个深度为 5（根结点深度为 1）的完全 3 叉树，按前序遍历的顺序给结点从 1 开始编号，则第 100 号结点的父结点是第（ ）号。

- A. 95
- B. 96
- C. 97
- D. 98

> **题解**
> 答案：C
> 解释：这棵树按「每层都满」的 3 叉树理解，深度 5 共 1 + 3 + 9 + 27 + 81 = 121 个结点。前序编号会把每棵子树编成连续的一段：根是 1 号，它的三棵子树依次占 2–41、42–81、82–121，所以 100 号落在第三棵子树（根为 82 号）里；82 号的三棵子树依次占 83–95、96–108、109–121，100 号落在第二棵（根为 96 号）里；96 号的三棵子树依次占 97–100、101–104、105–108，100 号落在第一棵（根为 97 号）里，而 97 号的孩子正好是 98、99、100 号，所以父结点是 97 号，选 C。A 项 95 是 82 号另一棵子树的末尾，B 项 96 是 100 号所在子树的根，D 项 98 是 100 号的兄弟。
> 争议：题目没有给出这棵树一共有多少个结点，而「完全」若按标准的「除最后一层外每层都满、最后一层从左到右填」来理解，最后一层有几个叶子会改变前序编号，答案也跟着变：最后一层取 60、61、62、63 个叶子时（对应 100、101、102、103 个结点），第 100 号结点的父结点分别是 97、98、99、82 号，只有最后一层满到 81 个叶子（共 121 个结点）时才是 97 号。本题按「每层都满的 3 叉树」理解并取 C 项；按严格定义读，这道题少了结点总数这个条件。

### 第 8 题

<!-- qid: csp-s1-2022-008 | type: single_choice | score: 2 | answer: B | tags: topic:graph -->

强连通图的性质不包括（ ）：

- A. 每个顶点的度数至少为 1
- B. 任意两个顶点之间都有边相连
- C. 任意两个顶点之间都有路径相连
- D. 每个顶点至少都连有一条边

> **题解**
> 答案：B
> 解释：强连通图只要求任意两个顶点之间互相可达（有路径相连），并不要求任意两点之间有一条边，所以「任意两个顶点之间都有边相连」不是它的性质，选 B。C 项正是强连通的定义；A 项与 D 项（每个顶点至少连有一条边）也必然成立——顶点数为 1 时它至少要能连到自己，顶点数更多时每个顶点都得能连到别的顶点，否则它孤立着，谈不上与任何点互相可达。

### 第 9 题

<!-- qid: csp-s1-2022-009 | type: single_choice | score: 2 | answer: D | tags: topic:combinatorics,topic:graph -->

每个顶点度数均为 2 的无向图称为“2 正规图”。由编号为从 1 到 n 的顶点构成的所有 2 正规图，其中包含欧拉回路的不同 2 正规图的数量为（ ）。

- A. n!
- B. (n-1)!
- C. n!/2
- D. (n-1)!/2

> **题解**
> 答案：D
> 解释：每个顶点度数都为 2 的图就是若干个互不相交的圈拼起来的。要求它含欧拉回路，就要求整张图连通（各点度数为偶数只是必要条件，几个不相交的圈之间无法一笔画走遍），于是整张图必须是一个经过全部 n 个顶点的圈。给 n 个标号顶点排成一个圈：n! 种排列里，绕圈循环移位（n 种）与整体反向（2 种）得到的是同一个圈，所以不同圈数为 n!/(2n) = (n−1)!/2，选 D。A 项 n!、C 项 n!/2 都没有除去循环移位带来的重复，B 项 (n−1)! 只除了循环移位、忘了圈没有方向。

### 第 10 题

<!-- qid: csp-s1-2022-010 | type: single_choice | score: 2 | answer: A | tags: topic:combinatorics -->

共有 8 人选修了程序设计课程，期末大作业要求由 2 人组成的团队完成。假设不区分每个团队内 2 人的角色和作用，请问共有多少种可能的组队方案。（ ）

- A. 28
- B. 32
- C. 56
- D. 64

> **题解**
> 答案：A
> 解释：方案数是 8 个人里任取 2 人、且两人不分角色，即组合数 C(8,2) = 8 × 7 ÷ 2 = 28，选 A。C 项 56 = 8 × 7 是「先选队长再选队员」按排列算的结果，多了一倍；B 项 32、D 项 64 都含有 2 的幂次，与 8 人取 2 的组合数不相干。

### 第 11 题

<!-- qid: csp-s1-2022-011 | type: single_choice | score: 2 | answer: C | tags: topic:combinatorics -->

小明希望选到形如“省A·ℒℒ𝒟𝒟𝒟”的车牌号。车牌号在“·”之前的内容固定不变；后面的 5 位号码中，前 2 位必须是大写英文字母，后 3 位必须是阿拉伯数字（ℒ代表 A 至 Z，𝒟 表示 0 至 9，两个 ℒ 和三个 𝒟 之间可能相同也可能不同）。请问总共有多少个可供选择的车牌号。（ ）

- A. 20280
- B. 52000
- C. 676000
- D. 1757600

> **题解**
> 答案：C
> 解释：`·` 前面固定的 `省A` 不影响计数，要算的是后 5 位：前 2 位各是 26 个大写字母之一，后 3 位各是 10 个数字之一，各位相互独立，共 26 × 26 × 10 × 10 × 10 = 676000，选 C。D 项 1757600 = 26³ × 10² 把字母位当成了 3 位，A 项 20280 = 26² × 30、B 项 52000 = 26 × 2 × 10³ 则是把字母位与数字位的个数数错了。

### 第 12 题

<!-- qid: csp-s1-2022-012 | type: single_choice | score: 2 | answer: D | tags: topic:ds -->

给定地址区间为 0~9 的哈希表，哈希函数为 h(x) = x % 10，采用线性探查的冲突解决策略（对于出现冲突情况，会往后探查第一个空的地址存储；若地址 9 冲突了则从地址 0 重新开始探查）。哈希表初始为空表，依次存储(71, 23, 73, 99, 44, 79, 89)后，请问 89 存储在哈希表哪个地址中。（ ）

- A. 9
- B. 0
- C. 1
- D. 2

> **题解**
> 答案：D
> 解释：依次插入并且同余时向后线性探查：71 落在 1；23 落在 3；73 与 23 同余（都是 3）被挤到 4；99 落在 9；44 与 73 同余被挤到 5；79 与 99 同余，9 已占，绕回 0；89 又同余于 9，9 被 99 占、0 被 79 占、1 被 71 占，所以落在 2，选 D。实跑模拟整张表的最终状态是 `[79, 71, 89, 23, 73, 44, -, -, -, 99]`，89 在地址 2。A 项 9 是哈希值本身（忘了冲突），B 项 0 是 79 的位置，C 项 1 是 71 的位置。

### 第 13 题

<!-- qid: csp-s1-2022-013 | type: single_choice | score: 2 | answer: B | tags: feat:formula,topic:complexity -->

对于给定的 n，分析以下代码段对应的时间复杂度，其中最为准确的时间复杂度为（ ）。

```
int i, j, k = 0;
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j*=2) {
        k = k + n / 2;
    }
}
```

- A. $O(n)$
- B. $O(n \log n)$
- C. $O(n\sqrt{n})$
- D. $O(n^2)$

> **题解**
> 答案：B
> 解释：外层 `i` 从 0 到 n−1 共 n 轮；内层的 `j` 每轮乘 2（1、2、4、8……），只要 `j < n` 就执行一次 `k = k + n / 2`，所以每个 `i` 要执行约 log₂n 次，总次数约为 n·log₂n，即 O(n log n)，选 B。A 项 O(n) 只在「每个 i 只做常数次」时才成立，漏掉了内层的对数因子；C 项 O(n√n)、D 项 O(n²) 都高估了内层次数——`j` 是按倍数增长的，不是每次加 1，最多也就是对数级。
> 争议：卷面这段代码的内层循环印的是 `for (j = 0; j < n; j*=2)`：`j` 的初值为 `0` 时 `j *= 2` 恒为 `0`，条件 `j < n` 永远成立，内层循环不会结束，照印出来的代码根本得不到答案，也就推不出 B 项。原卷印的确实是 `0`（PDF 文本层提取与 300 dpi 渲染目视都确认过），本题按「照录不订正」保留原样，答案仍取与 `j = 1` 写法一致的 B 项；做题时把这一行读作 `j = 1`。

### 第 14 题

<!-- qid: csp-s1-2022-014 | type: single_choice | score: 2 | answer: B | tags: topic:complexity -->

以比较为基本运算，在 n 个数的数组中找最大的数，在最坏情况下至少要做（ ）次运算。

- A. n/2
- B. n-1
- C. n
- D. n+1

> **题解**
> 答案：B
> 解释：在 n 个数里找最大值，最坏情况下至少要比较 n − 1 次：每比较一次最多只能让一个数「处于下风」，除最大值以外的 n − 1 个数都必须至少输过一次，否则无法断定谁最大，所以 n − 1 是下界；按「先取第一个数当当前最大，之后每个数与它比一次、更大就替换」的做法正好是 n − 1 次，可以取到，选 B。A 项 n/2 覆盖不了全部元素，C 项 n、D 项 n+1 都比必要次数多。

### 第 15 题

<!-- qid: csp-s1-2022-015 | type: single_choice | score: 2 | answer: B | tags: topic:sim -->

ack 函数在输入参数“(2,2)”时的返回值为（ ）。

```
unsigned ack(unsigned m, unsigned n) {
  if (m == 0) return n + 1;
  if (n == 0) return ack(m - 1, 1);
  return ack(m - 1, ack(m, n - 1));
}
```

- A. 5
- B. 7
- C. 9
- D. 13

> **题解**
> 答案：B
> 解释：把函数抄成程序实跑，`ack(2, 2)` 返回 7，选 B。也可以按定义手工展开：由 `ack(0, n) = n + 1` 得 `ack(1, n) = ack(0, ack(1, n−1)) = ack(1, n−1) + 1 = n + 2`，于是 `ack(2, n) = ack(1, ack(2, n−1)) = ack(2, n−1) + 2 = 2n + 3`，代入 n = 2 得 7。A 项 5、C 项 9、D 项 13 都是把递归展开算错（例如漏掉 `ack(m, n−1)` 那次内层调用）得到的结果。

```cpp

  3  #include <vector>
  4
  5  using namespace std;
  6
  7  int f(const string &s, const string &t)
  8  {
  9      int n = s.length(), m = t.length();
 10

 12
 13      int i, j;
 14

 16          shift[t[j]] = m - j;

 22      }
 23
 24      return -1;
 25  }
 26
 27  int main()
```

（容器分水）有两个容器，容器 1 的容量为为 a 升，容器 2 的容量为 b 升；同时允许下列的三种操作，分别为：

1）FILL(i)：用水龙头将容器 i（i∈{1,2}）灌满水；

```cpp
  2  using namespace std;
  3  const int N = 110;
  4
  5  int f[N][N];
  6  int ans;
  7  int a, b, c;
  8  int init;
  9
 10  int dfs(int x, int y) {
 11    if (f[x][y] != init)
 12      return f[x][y];

 14      return f[x][y] = 0;

 17    f[x][y] = min(f[x][y], dfs(x, b) + 1);

 21    f[x][y] = min(f[x][y], ①);
 22    t = min(x, b - y);
 23    f[x][y] = min(f[x][y], ②);
 24    return f[x][y];
 25  }
 26

 28    if (③)
 29      return;
 30    if (f[x][y] == dfs(a, y) + 1) {
 31      cout << "FILL(1)" << endl;
 32      go(a, y);
 33    } else if (f[x][y] == dfs(x, b) + 1) {
 34      cout << "FILL(2)" << endl;
 35      go(x, b);
 36    } else if (f[x][y] == dfs(0, y) + 1) {
 37      cout << "DROP(1)" << endl;
 38      go(0, y);
 39    } else if (f[x][y] == dfs(x, 0) + 1) {
 40      cout << "DROP(2)" << endl;
 41      go(x, 0);
 42    } else {
 43      int t = min(a - x, y);
 44      if (f[x][y] == ④) {
 45        cout << "POUR(2,1)" << endl;
 46        go(x + t, y - t);
 47      } else {
 48        t = min(x, b - y);
 49        if (f[x][y] == ⑤) {
 50          cout << "POUR(1,2)" << endl;

 52        } else

 55    }
```

> 解释：⑤ 所在的 else 分支处理 POUR(1,2)：这里 `t = min(x, b - y)`，后继状态是 `(x - t, y + t)`，紧接着的递归调用是 `go(x - t, y + t)`，所以 ⑤ 填 `f[x][y] == dfs(x - t, y + t) + 1`，选 C。A、B 两项写成 `(x + t, y - t)`，方向与这次的 t 相反；D 项把同一状态写成 `- 1`。它与 ④ 互为镜像，正确的一对必须与各自分支打印的操作名一致；实跑对拍只有 C 通过。

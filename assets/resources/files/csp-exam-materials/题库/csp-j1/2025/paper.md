### 第 1 题

<!-- qid: csp-j1-2025-001 | type: single_choice | score: 2 | answer: A | tags: feat:formula,topic:number -->

一个 32 位无符号整数可以表示的最大值，最接近下列哪个选项？（ ）

- A. $4 \times 10^9$
- B. $3 \times 10^{10}$
- C. $2 \times 10^9$
- D. $2 \times 10^{10}$

> **题解**
> 答案：A
> 解释：32 位无符号整数的最大值是 2³² − 1 = 4294967295。与四个选项作差：离 A 项 4 × 10⁹ 约差 2.95 亿，离 C 项 2 × 10⁹ 约差 22.95 亿，B、D 两项都是 10¹⁰ 量级、差到 1.5 × 10¹⁰ 以上。所以最接近的是 A。另一种看法：2³² = 4294967296 ≈ 4.29 × 10⁹，首位数字就是 4，B、C、D 的量级都对不上。

### 第 2 题

<!-- qid: csp-j1-2025-002 | type: single_choice | score: 2 | answer: B | tags: topic:bit -->

在 C++ 中，执行 `int x = 255; cout << (x & (x - 1));` 后，输出的结果是？（ ）

- A. 255
- B. 254
- C. 128
- D. 0

> **题解**
> 答案：B
> 解释：`x = 255`，`x - 1 = 254`。按位与只保留两个数对应位同时为 1 的位：255 是 `0b11111111`，254 是 `0b11111110`，只有最低位不同、相与后最低位为 0，其余七位仍是 1，结果是 `0b11111110` 即 254，选 B。A 项 255 是根本没做运算的 `x` 本身；C 项 128 只留下最高位；D 项 0 要求两数没有任何一位同为 1，而这两个数有七位同为 1。把这一行原样编译运行，输出就是 `254`。
> 争议：第三方答案来源（「自主选拔在线」公众号整理的参考答案，非官方）给 D，本卷取 B。把卷面这一行原样编译运行，输出就是 `254`：255 是 `0b11111111`、254 是 `0b11111110`，逐位相与只有最低位为 0、其余七位仍为 1，结果正是 254。该来源的题解把理由写成「255 与 254 按位与结果为 0」，这既与实际运算结果不符，也与它自己给的 D 对不上——只有按位与真的等于 0 时才谈得上选 D。

### 第 3 题

<!-- qid: csp-j1-2025-003 | type: single_choice | score: 2 | answer: B | tags: topic:lang -->

函数 `calc(n)` 的定义如下，则 `calc(5)` 的返回值是多少？（ ）

```
int calc(int n) {
    if (n <= 1) return 1;
    if (n % 2 == 0) return calc(n / 2) + 1;
    else return calc(n - 1) + calc(n - 2);
}
```

- A. 5
- B. 6
- C. 7
- D. 8

> **题解**
> 答案：B
> 解释：从 n = 0 起逐项递推：`calc(0) = calc(1) = 1`（都走 `n <= 1` 这一支）；`calc(2) = calc(1) + 1 = 2`；`calc(3) = calc(2) + calc(1) = 2 + 1 = 3`；`calc(4) = calc(2) + 1 = 3`；`calc(5) = calc(4) + calc(3) = 3 + 3 = 6`。所以选 B。四个选项只差 1，靠估算是分不出来的，必须把序列写出来：`calc(0..8)` 是 1, 1, 2, 3, 3, 6, 4, 10, 4——A 项 5 相当于把奇数那一支错算成 `calc(4) + calc(2)`，C 项 7、D 项 8 也都比递推值大。

### 第 4 题

<!-- qid: csp-j1-2025-004 | type: single_choice | score: 2 | answer: B | tags: topic:tree -->

用 5 个权值 10, 12, 15, 20, 25 构造哈夫曼树，该树的带权路径长度是多少？（ ）

- A. 176
- B. 186
- C. 196
- D. 206

> **题解**
> 答案：B
> 解释：哈夫曼树每次取两个最小的权值合并，合并出的新权值放回集合再继续：10 + 12 = 22（剩 15, 20, 22, 25）；15 + 20 = 35（剩 22, 25, 35）；22 + 25 = 47（剩 35, 47）；35 + 47 = 82。带权路径长度等于所有合并值之和，22 + 35 + 47 + 82 = 186，选 B。也可以按深度验算：10 与 12 在下三层，15、20、25 在下两层，3 × (10 + 12) + 2 × (15 + 20 + 25) = 66 + 120 = 186，两条路给出同一个数。A 项 176 与这个和不等。
> 争议：第三方来源给 A（176），本卷取 B。按 5 个权值逐步合并：10 + 12 = 22、15 + 20 = 35、22 + 25 = 47、35 + 47 = 82，带权路径长度是这些合并值之和，22 + 35 + 47 + 82 = 186；换一条路按每个权值的深度算（10 与 12 在第 3 层、其余三个在第 2 层），3 × 22 + 2 × 60 = 66 + 120 = 186。两种算法都得到 186，与 A 项 176 都不等。

### 第 5 题

<!-- qid: csp-j1-2025-005 | type: single_choice | score: 2 | answer: B | tags: topic:graph -->

在一个有向图中，所有顶点的入度之和等于所有顶点的出度之和，这个总和等于？（ ）

- A. 顶点数
- B. 边数
- C. 顶点数 + 边数
- D. 顶点数 * 2

> **题解**
> 答案：B
> 解释：每一条有向边都从一个顶点出发、指向一个顶点，所以它对「所有顶点的出度之和」贡献 1，对「所有顶点的入度之和」也贡献 1。把 E 条边全部加起来，两个总和都等于边数 E，也就是入度之和 = 出度之和 = 边数，选 B。A、C、D 三项都跟 E 无关：自环、重边、孤立顶点都不改变这个等式，例如 3 个顶点 2 条边的图，入度之和一定是 2，与顶点数是 3 无关。

### 第 6 题

<!-- qid: csp-j1-2025-006 | type: single_choice | score: 2 | answer: C | tags: topic:combinatorics -->

从 5 位男生和 4 位女生中选出 4 人组成一个学习小组，要求学习小组中男生和女生都有。有多少种不同的选举方法？（ ）

- A. 126
- B. 121
- C. 120
- D. 100

> **题解**
> 答案：C
> 解释：先按不分组算：9 个人里任选 4 人共 C(9,4) = 126 种。要保证男生女生都有，就把两类不合要求的选法减掉：4 人全是男生有 C(5,4) = 5 种，4 人全是女生有 C(4,4) = 1 种。126 − 5 − 1 = 120，选 C。D 项 100、A 项 126 分别是少减与根本没减的干扰值。
> 争议：第三方答案来源（「自主选拔在线」公众号整理的参考答案，非官方）给 B（121），本卷取 C。把算式写全：C(9,4) = 126，C(5,4) = 5，C(4,4) = 1，126 − 5 − 1 = 120。该来源自己的题解写的是「C(9,4) 减去 C(5,4) 和 C(4,4)，得 121」，也就是它列的式子和它的得数互相矛盾——126 − 5 − 1 只能是 120。

### 第 7 题

<!-- qid: csp-j1-2025-007 | type: single_choice | score: 2 | answer: C | tags: topic:lang -->

假设 a, b, c 都是布尔变量，逻辑表达式 (a && b) || (!c && a) 的值与下列哪个表达式不始终相等？（ ）

- A. a && (b || !c)
- B. (a || !c) && (b || !c) && (a || a)
- C. a && (!b || c)
- D. !(!a || !b) || (a && !c)

> **题解**
> 答案：C
> 解释：把 a、b、c 的 8 种取值逐个代入原式 E = (a && b) || (!c && a)：a = 0 时 E 恒为 0；a = 1 时 E 等于 b || !c，于是 E = a && (b || !c)。C 项是 a && (!b || c)，在 (a, b, c) = (1, 0, 1) 时 E = 0 而 C 项 = 1，在 (1, 1, 0) 时 E = 1 而 C 项 = 0，两行都不同，所以在 8 行真值表里 C 有 2 行与 E 不等。A 项就是化简后的形式、恒等；B 项里 a || a 等于 a，整个式子也化简为 a && (b || !c)；D 项 !(!a || !b) || (a && !c) = (a && b) || (a && !c) = a && (b || !c)，同样恒等。故选 C。

### 第 8 题

<!-- qid: csp-j1-2025-008 | type: single_choice | score: 2 | answer: D | tags: topic:number -->

已知 f[0] = 1, f[1] = 1, 并且对于所有 n ≥ 2 有 f[n] = (f[n-1] + f[n-2]) % 7。那么 f[2025] 的值是多少？（ ）

- A. 2
- B. 4
- C. 5
- D. 6

> **题解**
> 答案：D
> 解释：递推每步只看前两项、又对 7 取模，所以序列必然出现周期。逐项写出前 16 项：1, 1, 2, 3, 5, 1, 6, 0, 6, 6, 5, 4, 2, 6, 1, 0；再算一项 f[16] = (0 + 1) % 7 = 1、f[17] = 1，与 f[0]、f[1] 相同，可见周期是 16。2025 ÷ 16 商 126 余 9，所以 f[2025] = f[9] = 6，选 D。A 项 2、B 项 4、C 项 5 都是这段序列里出现过的值，只有算准周期与余数才能排除。

### 第 9 题

<!-- qid: csp-j1-2025-009 | type: single_choice | score: 2 | answer: B | tags: topic:lang -->

下列关于 C++ `string` 类的说法，正确的是？（ ）

- A. `string` 对象的长度在创建后不能改变。
- B. 可以使用 `+` 运算符直接连接一个 `string` 对象和一个 `char` 类型的字符。
- C. `string` 的 `length()` 和 `size()` 方法返回的值可能不同。
- D. `string` 对象必须以 `'\0'` 结尾，且这个结尾符计入 `length()`。

> **题解**
> 答案：B
> 解释：逐项验证：A 项错，`s = "abc"` 之后执行 `s += "def"`，长度从 3 变成 6，长度显然可变；C 项错，`length()` 与 `size()` 是同一个含义的两种写法，对 `"hello"` 都返回 5，不会不同；D 项错，`string` 不要求以 `'\0'` 结尾，`y[5]` 读到的是结束符，它并不计入 `length()`。B 项对：`string` 对象与单个 `char` 可以直接用 `+` 连接，设 `s = "ab"`，则 `s + 'c'` 得 `"abc"`、`'c' + s` 得 `"cab"`，两个方向的重载都存在，都能编译且结果正确。

### 第 10 题

<!-- qid: csp-j1-2025-010 | type: single_choice | score: 2 | answer: C | tags: topic:lang -->

考虑以下 C++ 函数：

```
void solve(int &a, int b) {
    a = a + b;
    b = a - b;
    a = a - b;
}
int main() {
    int x = 5, y = 10;
    solve(x, y);
}
```

在 `main` 函数调用 `solve` 后，x 和 y 的值分别是？（ ）

- A. 5, 10
- B. 10, 5
- C. 10, 10
- D. 5, 5

> **题解**
> 答案：C
> 解释：形参表是 `int &a, int b`：`a` 是引用，就是 `x` 本身；`b` 是按值传递的副本。逐步代入：`a = a + b` 之后 `a`（也就是 `x`）变成 15，而 `b` 仍是 10；`b = a - b` 只改副本、得 5，`x` 不变；`a = a - b` 让 `x` 变成 15 − 5 = 10。调用结束后 `x = 10`，而 `y` 从头到尾没被写过，仍是 10，所以选 C。把这段代码原样编译运行，输出就是 `10 10`。
> 争议：第三方来源给 B（`10, 5`），本卷取 C。差别只在 `b` 是不是引用：卷面印的是 `void solve(int &a, int b)`，只有 `a` 带 `&`。把这一行原样抄进 `.cpp` 编译运行，`x = 5, y = 10` 调用后输出 `10 10`；来源是按「两个形参都是引用」的交换写法作答，才会得到 `10 5`。按卷面代码，`b` 只是副本，`y` 不可能被改成 5。

### 第 11 题

<!-- qid: csp-j1-2025-011 | type: single_choice | score: 2 | answer: B | tags: topic:combinatorics -->

一个 8×8 的棋盘，左上角坐标为 (1,1)，右下角为 (8,8)。一个机器人从 (1,1) 出发，每次只能向右或向下走一格。要到达 (4,5)，有多少种不同的路径？（ ）

- A. 20
- B. 35
- C. 56
- D. 70

> **题解**
> 答案：B
> 解释：从 (1,1) 走到 (4,5)，行号要增加 3、列号要增加 4，一共走 7 步，其中任选 3 步向下、其余 4 步向右，方案数就是 C(7,3) = 35，选 B。A 项 20 是 6 步里取 3 步的组合数，C 项 56 = C(8,3)、D 项 70 = C(8,4) 都按 8 步算，都比实际步数多了一步。
> 争议：第三方来源印出的答案是 A，但它同一页的题解里写着「原答案 A 错误，正确答案 B」，字母与理由自相矛盾；本卷取 B。重算：需要向下 3 步、向右 4 步，共 7 步，路径数 C(7,3) = 35，与 B 项一致。

### 第 12 题

<!-- qid: csp-j1-2025-012 | type: single_choice | score: 2 | answer: B | tags: topic:sort -->

某同学用冒泡排序对数组 {6, 1, 5, 2, 4} 进行升序排序，请问需要进行多少次元素交换？（ ）

- A. 5
- B. 6
- C. 7
- D. 8

> **题解**
> 答案：B
> 解释：冒泡排序每交换一次相邻元素就消掉一个逆序对，总交换次数正好等于数组的逆序对数。{6, 1, 5, 2, 4} 的逆序对有 (6,1)、(6,5)、(6,2)、(6,4)、(5,2)、(5,4)，共 6 对，所以交换 6 次，选 B。逐趟实算也是 6：第一趟 4 次交换把 6 送到末尾（得 1, 5, 2, 4, 6），第二趟 2 次把 5 与 4 归位（得 1, 2, 4, 5, 6），之后已无逆序、不再交换。A 项 5、C 项 7、D 项 8 与逆序对数都不符。

### 第 14 题

<!-- qid: csp-j1-2025-014 | type: single_choice | score: 2 | answer: C | tags: topic:tree -->

一棵包含 1000 个结点的完全二叉树，其叶子结点的数量是多少？（ ）

- A. 499
- B. 512
- C. 500
- D. 501

> **题解**
> 答案：C
> 解释：在完全二叉树里按下标编号后，结点 i 有左孩子当且仅当 2i ≤ n。n = 1000 时 1 号到 500 号结点有孩子，501 号到 1000 号都没有，所以叶子数是 1000 − 500 = 500，选 C。把它写成公式就是「完全二叉树的叶子数 = n − ⌊n/2⌋」：⌊1000/2⌋ = 500，1000 − 500 = 500。
> 争议：第三方来源给 D（501），本卷取 C。重算：有孩子的结点满足 2i ≤ 1000，即 i ≤ 500，共 500 个，叶子数 = 1000 − 500 = 500，与公式 n − ⌊n/2⌋ = 500 一致。501 比公式值多 1，与 1000 个结点的完全二叉树不符。

### 第 15 题

<!-- qid: csp-j1-2025-015 | type: single_choice | score: 2 | answer: A | tags: topic:ds -->

给定一个初始为空的整数栈 S 和一个空的队列 P。我们按顺序处理输入的整数队列 A：7, 5, 8, 3, 1, 4, 2。对于队列 A 中的每一个数，执行以下规则：如果该数是奇数，则将其压入栈 S；如果该数是偶数，且栈 S 非空，则弹出一个栈顶元素，并加入到队列 P 的末尾：如果该数是偶数，且栈 S 为空，则不进行任何操作。当队列 A 中的所有数都处理完毕后，队列 P 的内容是什么？（ ）

- A. 5, 1, 3
- B. 7, 5, 3
- C. 3, 1, 5
- D. 5, 1, 3, 7

> **题解**
> 答案：A
> 解释：按规则逐个处理：7 是奇数、入栈，栈 {7}；5 是奇数、入栈，栈 {7, 5}；8 是偶数、栈非空，弹出栈顶 5 进队列；3、1 是奇数、依次入栈，栈 {7, 3, 1}；4 是偶数，弹出栈顶 1 进队列；2 是偶数，弹出栈顶 3 进队列。最后队列 P 的内容是 5, 1, 3，选 A。入栈的奇数有 7、5、3、1 共 4 个，遇到偶数只弹了 3 次，所以 7 一直压在栈底、从未进入队列——B 项 7, 5, 3 与 D 项多出的那个 7 都是这么错的；C 项把出栈顺序倒过来写了。

## 二、阅读程序

> 程序输入不超过数组或字符串定义的范围；判断题正确填 √，错误填 ×；除特殊说明外，判断题 1.5 分，选择题 3 分，共计 40 分。

### (1)

<!-- group: 阅读程序(1) -->

```cpp
 01  #include <algorithm>
 02  #include <cstdio>
 03  #include <cstring>
 04  inline int gcd(int a, int b) {
 05      if (b == 0)
 06          return a;
 07      return gcd(b, a % b);
 08  }
 09  int main() {
 10      int n;
 11      scanf("%d", &n);
 12      int ans = 0;
 13      for (int i = 1; i <= n; ++i) {
 14          for (int j = i + 1; j <= n; ++j) {
 15              for (int k = j + 1; k <= n; ++k) {
 16                  if (gcd(i, j) == 1 && gcd(j, k) == 1
 17                          && gcd(i, k) == 1) {
 18                      ++ans;
 19                  }
 20              }
 21          }
 22      }
 23      printf("%d\n", ans);
 24      return 0;
 25  }
```

> **程序说明**
> 这段程序读入一个整数 n，统计 1 到 n 之间有多少个三元组 (i, j, k) 满足 i < j < k 且两两互质（互质用递归写的辗转相除法判断，最大公约数等于 1 才算），最后输出这个三元组的个数。三重循环按 i < j < k 枚举全部组合，第 16 行的三个 `gcd` 条件要同时成立才会把答案加一。理解本组要抓住两点：一是「互质」必须两两都满足，只要有一对不互质整个三元组就不算，所以第 16 行删掉其中任何一个条件统计都会变松、答案都会变大；二是无论 n 多大，(1, 2, 3) 这三个数总是两两互质的，所以 n ≥ 3 时答案至少有 1、恒为正整数。

#### 判断题

##### 第 16 题

<!-- qid: csp-j1-2025-016 | type: true_false | score: 1 | answer: T | tags: feat:lineref,topic:number -->

（1 分）当输入为 2 时，程序并不会执行第 16 行的判断语句。（ ）

 05  int n, k;
 06  int a[200007];

（字符串解码）“行程长度编码”（Run-Length Encoding）是一种无损压缩算法，常用于压缩重复字符较多的数据，以减少存储空间。假设原始字符串不包含数字字符。压缩规则如下：i）如果原始字符串中一个字符连续出现 N 次（N≥2），在压缩字符串中它被表示为“字符+数字 N”。例如，编码“A12”代表 12 个连续的字符 A。ii）如果原始字符串中一个字符只出现 1 次，在压缩字符串中它就表示为该字符本身。例如，编码“B”代表 1 个字符 B。

以下程序实现读取压缩字符串并输出其原始的、解压后的形式。试补全程序。

```cpp
 01  #include <cctype>
 02  #include <iostream>
 03  #include <string>
 04  using namespace std;
 05
 06  int main() {
 07      string z;
 08      cin >> z;
 09      string s = "";
 10
 11      for (int i = 0; i < z.length(); ) {
 12          char ch = z[i];
 13
 14          if (① && isdigit(z[i + 1])) {
 15              i++;
 16              int count = 0;
 17              while (i < z.length() && isdigit(z[i])) {
 18                  count = ②;
 19                  i++;
 20              }
 21              for (int j = 0; j < ③; ++j) {
 22                  s += ch;
 23              }
 24          } else {
 25              s += ④;
 26              ⑤;
 27          }
 28      }
 29
 30      cout << s << endl;
 31      return 0;
 32  }
```

> **程序说明**
> 这段程序把行程长度编码（形如 `A12` 表示 12 个 A、`B` 表示 1 个 B）展开成原始字符串。它从左到右扫编码串：若当前字符后面紧跟着数字，就把这串数字读成整数（逐位乘 10 累加），再把这个字符重复输出那么多次；否则该字符只出现一次，直接接到结果末尾并让下标前进一格。输入是一行不含空白的压缩字符串，输出是解压后的字符串。理解本组要抓住两点：一是「字符 + 数字」里的数字可能有多位，必须按十进制逐位累加，不能只取最后一位，也不能把各位数字相加；二是无论走哪条分支下标都必须前进，否则会在同一个字符上反复处理、程序卡死。

（精明与糊涂）有 N 个人，分为两类：i）精明人：永远能正确判断其他人是精明还是糊涂；ii）糊涂人：判断不可靠，会给出随机的判断。已知精明人严格占据多数，即如果精明人有 k 个，则满足 k > N/2。

 16              candidate = i;
 17              count = 1;
 18          } else {
 19              if (③) {
 20                  ④;

 24          }

> 解释：⑤ 要输出最后留下的候选者，也就是 `candidate`，选 C。A 项 `N - 1` 与判断结果无关，永远输出最后一个人的编号；B 项 `count` 是票数、不是人的编号，可能为 0 或其它值；D 项固定输出 0，等于没做任何消除。把这三项代进去实跑，在 18242 种情形里都会印出糊涂人：A 项 `N - 1` 与 D 项 `0` 各错 6204 种，B 项 `count` 错 6018 种。只有输出 `candidate` 才符合这条不变量：每消掉的一对里至少有一个糊涂人，而精明人本来就过半，所以最后剩下的候选者不可能被消成糊涂人。

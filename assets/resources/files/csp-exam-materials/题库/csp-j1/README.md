# CSP-J 入门级第一轮

本目录存放 **CSP-J（入门级）** 试卷，每年一个子目录：

```
题库/csp-j1/<年份>/
├── <年份>-试题.pdf    # 源 PDF 副本
├── paper.md           # 试卷正文
├── meta.json          # 结构化元数据
└── assets/            # 插图
```

## 与 CSP-S 的差异

格式**完全相同**，只有两个字段不同：

| 字段 | CSP-J 取值 |
|---|---|
| `exam` | `CSP-J1` |
| `paper_id` | `csp-j1-<年份>` 或 `csp-j1-<年份><卷别>`，如 `csp-j1-2019` |

题目编号、题块注释、`tags` 词表、代码行号约定等一律沿用 [SPEC.md](../../SPEC.md)，
无需为入门级另立规则。

## 考纲

CSP-J 对应 [《NOI 大纲（2025 年修订版）》](../../资料/NOI大纲-2025-考点.md) 的
**入门级**，难度系数范围 **1~5**。

考纲规定「高级别自动包含低级别知识点」，因此入门级考点是提高级的子集——
两个组别**共用同一套 `topic:` 词表**，不需要为 J 组新建标签。

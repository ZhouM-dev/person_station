### 第 1 题

<!-- qid: csp-j1-2024-001 | type: single_choice | score: 2 | answer: C | tags: topic:lang -->

32 位 `int` 类型的存储范围是？（ ）

- A. -2147483647 ~ +2147483647
- B. -2147483647 ~ +2147483648
- C. -2147483648 ~ +2147483647
- D. -2147483648 ~ +2147483648

> **题解**
> 答案：C
> 解释：32 位 `int` 用补码表示，取值范围是 −2³¹ 到 2³¹ − 1，也就是 −2147483648 到 2147483647，选 C。32 位里最高位是符号位，正数最大只能到 2³¹ − 1 = 2147483647；A、B 两项把负数端点写成 −2147483647，D 项把正数端点写成 +2147483648，都与补码范围不符。

计算$(14_8 - 1010_2) * D_{16} - 1101_2$ 的结果，并选择答案的十进制值：（ ）

- A. 13
- B. 14
- C. 15
- D. 16

> **题解**
> 答案：A

### 第 3 题

<!-- qid: csp-j1-2024-003 | type: single_choice | score: 2 | answer: B | tags: topic:combinatorics -->

某公司有 10 名员工，分为 3 个部门：A 部门有 4 名员工、B 部门有 3 名员工、C 部门有 3 名员工。现需要从这 10 名员工中选出 4 名组成一个工作小组，且每个部门至少要有 1 人。问有多少种选择方式?（ ）

- A. 120
- B. 126
- C. 132
- D. 238

> **题解**
> 答案：B
> 解释：4 个人分给 3 个部门、每部门至少 1 人，只可能是 (2,1,1)、(1,2,1)、(1,1,2) 三种分配。按部门人数取组合：C(4,2)×C(3,1)×C(3,1) = 6 × 3 × 3 = 54，C(4,1)×C(3,2)×C(3,1) = 4 × 3 × 3 = 36，C(4,1)×C(3,1)×C(3,2) = 4 × 3 × 3 = 36，合计 54 + 36 + 36 = 126，选 B。用容斥核对：C(10,4) − 2×C(7,4) − C(6,4) + C(4,4) = 210 − 70 − 15 + 1 = 126。C 项 132、D 项 238 都没有正确体现「哪个部门出 2 人」这个唯一的分类结构，D 项甚至比不分部门的 C(10,4) = 210 还大。

### 第 4 题

<!-- qid: csp-j1-2024-004 | type: single_choice | score: 2 | answer: D | tags: topic:number -->

以下哪个序列对应数字 0 至 8 的 4 位二进制格雷码（Gray code）？（ ）

- A. 0000, 0001, 0011, 0010, 0110, 0111, 0101, 1000
- B. 0000, 0001, 0011, 0010, 0110, 0111, 0100, 0101
- C. 0000, 0001, 0011, 0010, 0100, 0101, 0111, 0110
- D. 0000, 0001, 0011, 0010, 0110, 0111, 0101, 0100

> **题解**
> 答案：D
> 解释：格雷码要求相邻两个码字只差 1 位。逐对比较四个选项：A 项最后一步 0101 → 1000 差 3 位；B 项 0111 → 0100 差 2 位；C 项 0010 → 0100 差 2 位；只有 D 项每一步都只差 1 位，而且它对应的十进制是 0、1、3、2、6、7、5、4，正是 4 位格雷码的前 8 项，选 D。

### 第 12 题

<!-- qid: csp-j1-2024-012 | type: single_choice | score: 2 | answer: A | tags: topic:tree -->

已知二叉树的前序遍历为 [A, B, D, E, C, F, G]，中序遍历为 [D, B, E, A, F, C, G]，请问该二叉树的后序遍历结果是？（ ）

- A. [D, E, B, F, G, C, A]
- B. [D, E, B, F, G, A, C]
- C. [D, B, E, F, G, C, A]
- D. [D, E, B, F, G, A, C]

> **题解**
> 答案：A
> 解释：前序遍历的第一个结点 A 是整棵树的根；在中序 [D, B, E, A, F, C, G] 里，A 左边的 D、B、E 属于左子树，右边的 F、C、G 属于右子树。左子树前序 [B, D, E] 说明它的根是 B、D 在 B 左、E 在 B 右；右子树前序 [C, F, G] 说明根是 C、F 在 C 左、G 在 C 右。按「左、右、根」写后序：左子树 D、E、B，右子树 F、G、C，最后是根 A，合起来是 [D, E, B, F, G, C, A]，选 A。C 项把左子树写成 D、B、E，那是中序的顺序而不是后序。

### 第 13 题

<!-- qid: csp-j1-2024-013 | type: single_choice | score: 2 | answer: D | tags: topic:ds -->

给定一个空栈，支持入栈和出栈操作。若入栈操作的元素依次是 1 2 3 4 5 6，其中 1 最先入栈、6 最后入栈，下面哪种出栈顺序是不可能的？（ ）

- A. 6 5 4 3 2 1
- B. 1 6 5 4 3 2
- C. 2 4 6 5 3 1
- D. 1 3 5 2 4 6

> **题解**
> 答案：D
> 解释：判断出栈序列能否出现，就按顺序模拟：需要某个数时就先把比它小的数依次入栈，再看栈顶是不是它。D 项要依次输出 1、3、5、2、4、6：弹出 1 后入栈 2、3 弹出 3，再入栈 4、5 弹出 5，此时栈里从底到顶是 2、4，序列下一个要的 2 被 4 压住、取不出来，所以 D 不可能，选 D。A、B、C 都能模拟出来：A 是全部入栈后全部弹出；B 是 1 出栈后入栈 2 到 6，再依次弹出 6、5、4、3、2；C 是入 1、2 弹 2，入 3、4 弹 4，入 5、6 弹 6、5，再弹 3、1。

### (1)

<!-- group: 阅读程序(1) -->

```cpp
 01  #include <iostream>
 02  using namespace std;
 03
 04  bool isPrime(int n) {
 05      if (n <= 1) {
 06          return false;
 07      }
 08      for (int i = 2; i * i <= n; i++) {
 09          if (n % i == 0) {
 10              return false;
 11          }
 12      }
 13      return true;
 14  }
 15
 16  int countPrimes(int n) {
 17      int count = 0;
 18      for (int i = 2; i <= n; i++) {
 19          if (isPrime(i)) {
 20              count++;
 21          }
 22      }
 23      return count;
 24  }
 25
 26  int sumPrimes(int n) {
 27      int sum = 0;
 28      for (int i = 2; i <= n; i++) {
 29          if (isPrime(i)) {
 30              sum += i;
 31          }
 32      }
 33      return sum;
 34  }
 35
 36  int main() {
 37      int x;
 38      cin >> x;
 39      cout << countPrimes(x) << " " << sumPrimes(x) << endl;
 40      return 0;
 41  }
```

> **程序说明**
> 这段程序读入一个正整数 x，输出两件事：x 以内（含 x）素数的个数与这些素数之和，也就是 `countPrimes(x)` 与 `sumPrimes(x)`。判断素数的 `isPrime` 用试除法：先排除小于等于 1 的数，再让 i 从 2 试到 i × i 超过 n 为止——合数一定有个不超过 √n 的因子，试到 √n 就够。理解这一组要抓住两点：一是两个统计函数共用同一个 `isPrime`，各小题改的只是外层循环或试除的上界；二是把试除上界放宽（改成 `i <= n / 2`）只是多做了几次除法、判定结果不变，而放宽到 `i <= n` 就会让 n 自己被当成因子，把所有数都判成合数，个数与和一起变成 0。

##### 第 20 题

<!-- qid: csp-j1-2024-020 | type: single_choice | score: 3 | answer: A | tags: topic:number -->

如果将 `for (int i = 2; i * i <= n; i++)`改为 `for (int i = 2; i <= n; i++)`，输入“10”时，程序的输出（ ）。

- A. 将不能正确计算 10 以内素数个数及其和
- B. 仍然输出“4”和“17”
- C. 输出“3”和“10”
- D. 输出结果不变，但运行时间更短

> **题解**
> 答案：A

### (2)

<!-- group: 阅读程序(2) -->

```cpp
 01  #include <iostream>
 02  #include <vector>
 03  using namespace std;
 04
 05  int compute(vector<int>& cost) {
 06      int n = cost.size();
 07      vector<int> dp(n+1, 0);
 08      dp[1] = cost[0];
 09      for (int i = 2; i <= n; i++) {
 10          dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1];
 11      }
 12      return min(dp[n], dp[n-1]);
 13  }
 14
 15  int main() {
 16      int n;
 17      cin >> n;
 18      vector<int> cost(n);
 19      for (int i = 0; i < n; i++) {
 20          cin >> cost[i];
 21      }
 22      cout << compute(cost) << endl;
 23      return 0;
 24  }
```

> **程序说明**
> 这是「最小花费爬楼梯」型的动态规划。输入 n 与 n 个花费，每次可以向上走 1 级或 2 级，踩到第 i 级要付出 `cost[i-1]`，要求算出走到第 n 级之上所付的最小总花费。程序用 `dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1]` 表示「到第 i 级为止的最小花费」，最后返回 `min(dp[n], dp[n-1])`（从第 n 级或第 n − 1 级跨出去）。理解这一组要抓住两点：一是 `dp` 记的是累计最小花费而不是元素最小值，所以它输出的一般不是数组里最小的那个数；二是 `dp` 的下标必须落在 0 到 n 之间，把它改成 `dp[i-3]` 之类会在 i 较小时越界（那是运行期错误，不是编译错误）。

#### 判断题

##### 第 21 题

<!-- qid: csp-j1-2024-021 | type: true_false | score: 1.5 | answer: T | tags: topic:dp -->

当输入的 `cost` 数组为{10, 15, 20}时，程序的输出为 15。（ ）

> **题解**
> 答案：√

（判断平方数）问题：给定一个正整数 n，希望判断这个数是否为完全平方数，即存在一个正整数 x 使得 x 的平方为 n。

试补全程序。

```cpp
 01  #include<iostream>
 02  #include<vector>
 03  using namespace std;
 04
 05  bool isSquare(int num) {
 06      int i = ①;
 07      int bound = ②;
 08      for (; i <= bound; ++i) {
 09          if (③) {
 10              return ④;
 11          }
 12      }
 13      return ⑤;
 14  }
 15  int main() {
 16      int n;
 17      cin >> n;
 18      if (isSquare(n)) {

 23      return 0;
```

（汉诺塔问题）给定三根柱子，分别标记为 A、B 和 C。初始状态下，柱子 A 上有若干个圆盘，这些圆盘从上到下按从小到大的顺序排列。任务是将这些圆盘全部移到柱子 C 上，且必须保持原有顺序不变。在移动过程中，需要遵守以下规则：

1. 只能从一根柱子的顶部取出圆盘，并将其放入另一根柱子的顶部。
2. 每次只能移动一个圆盘。
3. 小圆盘必须始终在大圆盘之上。

试补全程序。

```cpp
 01  #include <iostream>
 02  #include <vector>
 03  using namespace std;
 04
 05  void move(char src, char tgt) {
 06      cout << "从柱子" << src << "挪到柱子" << tgt << endl;
 07  }
 08  void dfs(int i, char src, char tmp, char tgt) {
 09      if (i == ①) {
 10          move(②);
 11          return;
 12      }
 13      dfs(i - 1, ③);
 14      move(src, tgt);
 15      dfs(⑤, ④);
 16  }
 17
 18  int main() {
 19      int n;
 20      cin >> n;
 21      dfs(n, 'A', 'B', 'C');
 22  }
```

> **程序说明**
> 这段程序用递归解汉诺塔：`dfs(i, src, tmp, tgt)` 表示把 src 柱上的 i 个盘子借助 tmp 柱搬到 tgt 柱。i 等于 1 时直接 `move(src, tgt)` 一步挪完，这就是递归出口；否则分三步——先把上面 i − 1 个盘子借助 tgt 搬到 tmp，再把最底下那个大盘从 src 搬到 tgt，最后把那 i − 1 个盘子借助 src 搬到 tgt。输入是盘子数 n，输出是每一步的移动过程。理解这一组的关键在参数的含义：每次递归都要重新指定「起点、中转、终点」三个角色，中转与终点还会互换；同时递归的规模必须逐层递减到 1，写成 `i` 就会永不收敛。

③处应填（ ）

- A. `src, tmp, tgt`
- B. `src, tgt, tmp`
- C. `tgt, tmp, src`
- D. `tgt, src, tmp`

> **题解**
> 答案：B
> 解释：③ 是「把上面 i − 1 个盘子从 src 搬到 tmp」那次递归，三个参数的顺序是起点、中转、终点，要借助 tgt 搬到 tmp，所以填 `src, tgt, tmp`，选 B。A 项 `src, tmp, tgt` 在 n = 2 时第 2 步就把大盘压到了小盘上；C 项 `tgt, tmp, src` 与 D 项 `tgt, src, tmp` 以 tgt（C 柱）为起点，第 1 步就要从空柱取盘。

##### 第 41 题

④处应填（ ）

- A. `src, tmp, tgt`
- B. `tmp, src, tgt`
- C. `src, tgt, tmp`
- D. `tgt, src, tmp`

> **题解**
> 答案：B
> 解释：④ 是「把那 i − 1 个盘子从中转柱 tmp 搬到目标柱 tgt」那次递归，要借助 src，所以填 `tmp, src, tgt`，选 B。A 项 `src, tmp, tgt` 与 C 项 `src, tgt, tmp` 都以已经空了的 src 柱为起点，n = 2 时第 3 步就要从空柱取盘；D 项 `tgt, src, tmp` 在 n = 2 时第 3 步把大盘压到小盘上。

##### 第 42 题

<!-- qid: csp-j1-2024-042 | type: single_choice | score: 3 | answer: C | tags: feat:circnum,topic:divide -->

⑤处应填（ ）

- A. 0
- B. 1
- C. `i - 1`
- D. `i`

> **题解**
> 答案：C
> 解释：⑤ 是第二次递归的规模，它必须比当前规模小一档，填 `i - 1` 时每层递归都处理 i − 1 个盘子，输出才正好是 2ⁿ − 1 步，选 C。实跑四个候选（n 取 1 到 4）：填 `i - 1` 得到 1、3、7、15 步，全部正确；填 1 在 n = 2 时凑巧也是 3 步，但 n = 3 只有 5 步、n = 4 只有 7 步（第二次递归只搬 1 个盘子，盘子一多就搬不完）；填 0 会让 `dfs(0, …)` 碰不到出口 1、参数一路减到负数（实跑 n ≥ 2 时以栈溢出中止，退出码 3221225725）；填 `i` 的参数根本不减小，同样不收敛（实跑在栈溢出前已打出约 86400 行移动）。

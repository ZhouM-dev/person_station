# 协作目录

多会话协作的通信区。**动手前先读 [角色与分工.md](角色与分工.md)**，本文件只是速查与模板。

---

## 谁能写什么

| 文件 | 唯一写者 |
|---|---|
| `角色与分工.md` | R0 |
| `看板.md` | R0 |
| `派工/<paper_id>.md` | R0 |
| `交付/<paper_id>.md` | R1 转写员 |
| `核验/<paper_id>.md` | R2 核验员 |

**一写一读。** 每份试卷三个文件，各写各的，并发不会撞车。

## 常见问题

**Q：改了 md 页面会同步吗？**
不会自动同步。页面是运行时读取，改完点顶栏「重新扫描」（需要目录授权模式）。

**Q：发现 SPEC 写得不清楚怎么办？**
不要自己拿主意。写进 `交付/<id>.md` 的「规范问题」，R0 裁决并更新 SPEC。

**Q：想要个新标签？**
不要自己加。写「标签申请」，R0 更新 TAGS.md 并跑 `gen_tags.py`。
在此之前先挂最接近的现有标签。

**Q：核验发现错误，我能直接改吗？**
不能。R2 只报告，改动由 R1 做——否则同一份文件两个写者，会互相覆盖。

# 转写员工作手册

**你是 R1 转写员，负责转换一个年份的试卷。**

---

## 怎么启动

把本文件路径交给一个新对话，并告知负责哪一年：

> 读 `F:\ai\试题\协作\手册\README.md`，你负责 CSP-S 2020 年。

新对话读完本文件后，按下面的「必读顺序」自行展开。

---

## 你的边界

| | |
|---|---|
| **可写** | `题库/<组别>/<年份>/`（`paper.md`、`meta.json`、`assets/`、源 PDF 副本）<br>`协作/交付/<paper_id>.md` |
| **只读** | `SPEC.md`、`TAGS.md`、`题目/`、`资料/`、`tools/`、其它年份目录 |
| **禁止** | ⛔ 写 `题库/index.json`（R0 登记）<br>⛔ 写其它年份目录<br>⛔ 改 `SPEC.md` / `TAGS.md` / `tools/`<br>⛔ 自行新增 `topic:` 标签 |

完整规程见 [角色与分工.md](../角色与分工.md)。**格式问题是 SPEC.md 说了算，流程和权限是本手册和角色文档说了算。**

## 年度对照表

派工前由 R0 用 `tools/survey_sources.py` 勘察，数据如下。

**目录一律是 `题库/csp-j1/<年份>/` 或 `题库/csp-s1/<年份>/`**，
`paper_id` 与组别目录必须自洽（`csp-j1-2021` 对 `csp-j1/2021/`），否则 `validate.py` 报错。

### CSP-S（提高级）

源文件在 `题目/*.pdf`（直接放根目录）。

| 年份 | 试题源 | 页数 | 答案源 | 特别点 |
|---|---|---|---|---|
| 2019 | 扫描件 | 10 | 无（用第三方，已映射） | ✅ 已完成，可作样板 |
| 2020 | **扫描件** | 13 | 无 | 走扫描件流程；无答案 |
| 2021 | 文本层 | 16 | **扫描件 30 页** | 答案要 OCR；程序代码在文本层里被转成了表格 |
| 2022 | 文本层 | 13 | **扫描件 1 页** | 答案要 OCR |
| 2023 | 文本层 | 13 | 文本层 1 页 | 答案全卷连续编号 |
| 2024 | 文本层 | 16 | 文本层 2 页 | 答案全卷连续编号 |
| 2025 | ⚠️ **文本层是广告水印** | 19 | 无 | **必须按扫描件处理** |

### CSP-J（入门级）

源文件在 `题目/csp-j/` **子目录**下，别去 `题目/` 根目录找。

| 年份 | 试题源 | 页数 | 答案源 | 特别点 |
|---|---|---|---|---|
| 2019 | **扫描件** | 9 | 官方答案表（文本层 1 页） | **B 卷**（`csp-j1-2019b`）；答案表按**节内编号**排，须映射到全卷连续号 |
| 2020 | **扫描件** | 10 | 官方答案表（文本层 1 页） | 答案表同样是节内编号；**卷别待核** |
| 2021 | 文本层 | 12 | **答题纸**（已填答案，文本层 1 页） | 不是普通答案表；答案用全卷连续编号，**且带分值标注** |
| 2022 | 文本层 | 12 | 答案表（文本层 1 页） | ⚠️ 首尾有 `=== ↓ junior ↓ ===`，疑为网页抓取；表里有 **44 个答案**（存疑） |
| 2023 | 文本层 | 10 | 答案表（文本层 1 页） | 纯符号网格，**无序号**，要自己数 |
| 2024 | 文本层 | 12 | 官方答案表（文本层 2 页） | 第 36 题官方注明「C (A 也算正确)」，`answer` 记 `C` |
| 2025 | **扫描件** | 9 | ⚠️ **第三方**（自主选拔在线） | 文件 xref 损坏但**渲染正常**；答案带题解，**第 33 题重复出现两次**，不可直接采信 |

> **CSP-J 与 CSP-S 的编号习惯不同**：J 的答案表（2019/2020/2021）用「第 N 题 → 判断题 1) 2) 3) 4) → 单选题 5) 6)」这种**节内编号**，
> 必须自己换算成全卷连续编号，**不要照抄原卷的分节号**。详见 [02-题号与分值.md](02-题号与分值.md)。

## 流程总览

```
① 判定源类型        → 01-源文件判定.md
② 转写 paper.md     → 02 题号分值 / 03 结构层级 / 04 文字公式
③ 提取插图          → 05-图片提取.md
④ 整理答案          → 06-答案处理.md
⑤ 标注标签          → 07-标签.md
⑥ 写 meta.json      → 08-元数据.md
⑦ 跑校验、交付      → 09-命令速查.md
```

**每一步都能单独做**，不必一次做完。中途卡住就写进 `协作/交付/<paper_id>.md` 上报。

## 交付清单

- [ ] `uv run python tools/validate.py 题库/<组别>/<年份>` → **退出码 0**
- [ ] `uv run python tools/tag_questions.py 题库 --check` → 通过
- [ ] `uv run python tools/lint_notes.py 题库/<组别>/<年份>` → **退出码 0**
      （每题的解释、每组的程序说明都合写作规范）
- [ ] `uv run python tools/gen_tags.py --check` → 通过
- [ ] `uv run python tools/gen_index.py` → 已重建总索引（新卷必须跑）
- [ ] 源 PDF 副本已放入年份目录，`source.sha256` 已填
- [ ] `_pages/`、`_tiles/` 等中间产物已删除
- [ ] `协作/交付/<paper_id>.md` 已填写

**校验失败就是没做完。** 不要绕过、不要注释掉检查。

## 卡住了怎么办

**不要停下来等人。** 写进 `协作/待决/<paper_id>.md`：

| 情况 | 怎么做 |
|---|---|
| 能按手册判定 | 自己决定，直接做 |
| 拿不准但**不阻塞** | 选最合理的方案 → 写待决文件 → **继续干** |
| 真正卡住推不动 | 写待决文件 → 交付已完成部分 → 停止 |

**已经自行决定的事也要写进待决文件**——R0 需要知道你在哪里做了判断。

格式见 [待决/README.md](../待决/README.md)。
关键是要写清「**我的处理**」，这样 R0 不在时工作照样能往下走。

---

## 四条铁律

1. **不猜。** 看不清就标存疑。题库给教学用，错答案比没答案危害大。
2. **不改共享文件。** 需要改，写进交付报告上报 R0。
3. **不跳校验。**
4. **不覆盖别人的文件。** 只写自己权限内的路径。

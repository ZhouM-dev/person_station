# 03 · 结构层级

`paper.md` 的结构是**下游解析器的合约**。层级写错，页面就会出怪象
（代码整段消失、`#### 选择题` 被当正文渲染出来）。

---

## 一、标题层级：四级各司其职

| 层级 | 用途 | 例子 |
|---|---|---|
| `##` | 节 | `## 二、阅读程序` |
| `###` | 大题组；或**第一节**的题目 | `### (1)`；`### 第 1 题` |
| `####` | 组内分栏 | `#### 判断题`、`#### 选择题` |
| `#####` | 题目（第二、三节） | `##### 第 16 题` |

规则：

- **第一节**没有大题组，题目直接用 `###`：`### 第 1 题`
- **第二、三节**先有 `###` 大题组，再有 `####` 分栏，题目用 `#####`
- `####` 分栏标题**只允许** `判断题` / `选择题` / `单选题` 三种
- 大题组标题（`### (1)`）与该组的 `<!-- group: -->` 注释配对出现

### ⚠️ 悬空内容是头号杀手

**代码块、提示、分栏标题都必须挂在某个分栏之下，不得悬空。**

曾经有过一次翻车：解析器只识别「题目」一种结构，凡是长在题目之外的内容——
组内那段程序代码、`#### 选择题` 这个分栏标题——都被并进了上一道题的正文。
表现为**代码整段消失**、`#### 选择题` 被当普通文字渲染出来。

排版时务必保证顺序：

```
### (1)
<!-- group: 阅读程序(1) -->
```cpp
（程序代码）
```
#### 判断题          ← 分栏在代码之后
##### 第 16 题        ← 题目在分栏之后
```

中间不要插入别的东西。

---

## 二、题块注释

紧跟题目标题之后，空一行，再写题干：

```markdown
### 第 1 题

<!-- qid: csp-s1-2019b-001 | type: single_choice | score: 2 | answer: C | tags: topic:lang -->

若有定义：`int a=7;` 则表达式……（ ）
```

字段顺序固定，以 ` | ` 分隔：

| 顺序 | 字段 | 必填 | 说明 |
|---|---|---|---|
| 1 | `qid` | 是 | 全卷连续编号 |
| 2 | `type` | 是 | `single_choice` / `true_false` |
| 3 | `score` | 是 | 数字，单位分 |
| 4 | `answer` | 否 | 单选 `A`~`D`；判断 `T`/`F` |
| 5 | `images` | 否 | 图片文件名，逗号分隔 |
| 6 | `tags` | 否 | 内容标签，逗号分隔，**逗号后不加空格** |

**选填字段为空时整段省略**，不要写 `answer:` 后面留空。

## 三、代码块：保留原卷行号

题目会直接引用行号（「将第 21 行中 `t` 的类型声明从 `int` 改为 `double`」），
**行号错了题目就废了。**

格式：行号右对齐占 **3 列**，后跟 **2 个空格**，再是代码原文（含原有缩进）。

````markdown
```cpp
  1  #include <cstdio>
  2  using namespace std;
  3  int n;
  4  int a[100];
  5
  6  int main() {
  7      scanf("%d", &n);
```
````

要点：

- 行号必须与原卷**一致**，含空行——**空行也要占一个行号**（上面第 5 行）
- 第 5 行写成 `  5` 即可，后面不要留空格
- 去掉行号还原可编译代码的规则：删除每行行首的 `^\s*\d+  `
- 围栏标注语言：` ```cpp `

> **为什么不把行号去掉让代码可编译？** 因为题目会引用行号，保真优先。
> 而且各年程序长度不同（19/31/28/50/34 行），没有别的办法保留引用关系。

---

## 四、带圈数字：原样保留

完善程序的待填空位沿用原卷的 `①` `②` `③` `④` `⑤`。

- **不得**替换成 `(1)`、`___`、`[1]` 等任何其它写法
- 代码块与题干中保持一致
- 每组完善程序从 ① 重新开始（34–38 用 ①②③④⑤，39–43 再用一遍）

## 六、自检

```powershell
uv run python tools/validate.py 题库/<组别>/<年份>
```

校验器会查：题号连续性、题块注释与 `meta.json` 是否一致、分节分值、图片引用、
代码块行号格式与连续性、标题层级。

# 05 · 图片提取

试卷里的插图（示意图、流程图、坐标图）要从 PDF 里裁出来单独存。

---

## 一、命名与存放

```
题库/<组别>/<年份>/assets/q015-fig1.png
```

- 命名：`q{题号3位}-fig{序号}.png`，题号用**全卷连续序号**
- 一题多图时序号递增：`q015-fig1.png`、`q015-fig2.png`
- 小题配图归到**所属大题号**
- 只允许 PNG，按原分辨率裁切，**不放大、不锐化**
- 文件名一经确定**不得更改**，`paper.md` 与 `meta.json` 同时引用

---

## 二、扫描件的提取流程

### ① 先把页面渲染成图

```powershell
uv run --with pymupdf python tools/render_pages.py `
    题目/2020-试题.pdf 题库/csp-s1/2020/_pages --dpi 200
```

输出 `_pages/p001.png` … `p0NN.png`，200dpi 下是 1653×2339。

### ② 定位插图，先粗裁再微调

```powershell
uv run --with pillow python tools/crop_region.py `
    题库/csp-s1/2020/_pages/p002.png 题库/csp-s1/2020/assets/q015-fig1.png `
    --box 615,1838,1025,2125 --trim --pad 12
```

参数：

| 参数 | 说明 |
|---|---|
| `--box left,top,right,bottom` | 原图像素坐标，原点在左上角 |
| `--trim` | 自动收紧四周白边，框大了也不怕 |
| `--pad N` | 裁完向外补 N 像素白边，避免贴边 |
| `--mask x1,y1,x2,y2` | 在裁切结果上**涂白**一块区域，可重复 |

**先用大框试裁，看图再收。** 不要指望一次框准。

### ③ 必须回看结果

裁完**一定要用 Read 工具看图确认**：

- [ ] 没有切掉笔画（尤其顶部、左侧）
- [ ] 没有残留杂字（上一行的文字尾巴、页码、水印）
- [ ] 图像完整居中，不贴边

---

## 三、`--mask`：处理窜入的杂字

扫描件的插图上方常紧贴上一行的文字。**这种残字和图形在垂直方向上往往重叠，
单靠矩形框分不开。**

2019 第 15 题就踩过：图上方有个「大。」（上一行「……数之和最大。」的尾巴），
它的底边和图形顶部的 `a₁,₁` 几乎齐平——往上挪框会切掉图形，往下挪去不掉残字。

解法是 `--mask`，坐标**相对裁切框左上角**：

```powershell
--box 615,1838,1025,2125 --mask 0,0,95,60
```

含义：在裁切结果的左上角 `(0,0)-(95,60)` 区域涂白。

**顺序**：先 `--mask` 再 `--trim` 再 `--pad`，这样涂白后的空白会被 trim 正确收紧。

## 四、文本层 PDF 的插图

2021 之后的试题有文本层，但**插图仍然是图像**，文本层里没有。两种做法：

1. **从 PDF 直接裁**：先用 `render_pages.py` 渲染成图，再走上面的流程
2. **看原 PDF 里的位置**：文本层能告诉你图在哪一页、附近是什么文字，方便定位

## 五、引用与校验

`paper.md` 里：

```markdown
![数字三角形排列示意图](assets/q015-fig1.png)
```

- 相对路径，相对 `paper.md` 所在目录
- 替代文本是**简短中文描述**，不能是文件名
- 图片单独成段，前后各留空行

`meta.json` 里：

```json
"images": ["q015-fig1.png"]
```

**三处必须一致**：`paper.md` 的引用、`meta.json` 的 `images`、`assets/` 里的文件。
`validate.py` 会检查——引用了不存在的图、或有孤儿图片，都会报错。

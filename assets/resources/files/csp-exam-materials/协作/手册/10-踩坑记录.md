# 10 · 踩坑记录

**开工前先读这篇。** 下面每一条都是真实发生过的，不是假想。

按**症状**编排——遇到怪现象时对号入座。

## §1 · 文本层是广告，不是题目

**最贵的一个坑。** 2025-试题.pdf 有 19 页文本层，看起来「有文本层=能直接转」，
但内容**全是「自主选拔在线」的公众号推广页**，真正的试卷是底下的扫描图。

直接转的后果：**得到 19 页广告，题目一道不剩。**

**防**：开工先跑

```powershell
uv run --with pymupdf python tools/survey_sources.py
```

只看「可信」列。`否(广告)` 就走扫描件流程。**永远不要只看「有没有文本层」。**

---

## §2 · A/B 卷选项顺序不同

CSP 分 A/B 卷，**题目相同、选项重排**。第三方答案表往往是另一卷的。

**实例**：2019 第 5 题正确答案是 `x=(int)(x*100+0.5)/100.0;`

| 卷别 | 该选项是第几个 |
|---|---|
| 我们的 B 卷 | **D** |
| 第三方来源 | **B** |

来源答案表写 `B`，直接抄就错了。2019 抽查的第 6、7、8、12、20 题**选项顺序全部被打乱**，
是系统性的。

**防**：**按选项内容映射，不能抄字母。** 逐题做，每题的置换都不同，没有统一规则。
详见 [06-答案处理.md](06-答案处理.md)。

> **反面教材**：这也是为什么不能图省事批量套一个置换表。

---

## §3 · 悬空内容被并进上一题

解析器按结构读文档：节 → 大题组 → 分栏 → 题目。**长在题目之外的内容必须挂在某个分栏下**，
否则会被并进上一道题的正文。

**症状**：代码整段消失；`#### 选择题` 被当普通文字渲染出来。

**正确排版**：

```
### (1)
<!-- group: 阅读程序(1) -->
```cpp
（程序代码）
```
#### 判断题          ← 分栏在代码之后
##### 第 16 题        ← 题目在分栏之后
```

**中间不要插别的东西。** 详见 [03-结构层级.md](03-结构层级.md)。

---

## §4 · 插图上的残字去不掉

扫描件的插图上方常紧贴上一行的文字，**残字和图形在垂直方向重叠，矩形框分不开**。

2019 第 15 题：图上方有个「大。」（上一行「……数之和最大。」的尾巴），
底边和图形顶部的 `a₁,₁` 几乎齐平——上挪切掉图形，下挪去不掉残字。

**防**：用 `--mask` 涂白指定区域（坐标相对裁切框左上角）：

```powershell
--box 615,1838,1025,2125 --mask 0,0,95,60
```

**裁完必须回看**，确认没切边、没残字。详见 [05-图片提取.md](05-图片提取.md)。

---

## §5 · 分值不能只按节默认推

原卷**只对部分小题标了分值**，其余用节默认（判断 1.5、选择 4）。但**同一节内分值可以不同**：

```
2019 阅读程序：
判断题：1分、1分、1.5分、1.5分    ← 前两题有显式「（1 分）」
选择题：3分、4分                   ← 第一题有显式「（3 分）」
```

**防**：逐题读原卷标注，没有标注才用默认。然后用总分自检：

```
30（单选） + 40（阅读） + 30（完善） = 100
```

不等就说明某题分错了。

> 2019 用「显式标注 + 节默认 + 总分约束」三者交叉，最终与官方答案表的分值列**逐题吻合**。

## §6 · 代码行号错位

题目会直接引用行号（「将第 21 行中 `t` 的类型声明从 `int` 改为 `double`」），
**行号错了题目就废了。**

格式：行号右对齐占 **3 列** + **2 个空格** + 代码原文。

**空行也要占一个行号**：

```
  3  int n;
  4  int a[100];
  5
  6  int main() {
```

第 5 行写成 `  5` 即可（后面不留空格）。详见 [03-结构层级.md](03-结构层级.md)。

## §7 · 转换器会把代码弄乱

文本层 PDF 用 `to_markdown` 转出来的**是草稿，不是成品**。

已知症状：

| 症状 | 实例 |
|---|---|
| 代码缩进丢失、被排成表格 | 2021 阅读程序的代码被转成了 Markdown 表格 |
| 上下标错位 | `F₁`、`O(n²)` 变成 `F1`、`O(n2)` |
| 表格串行 | 选项被塞进单元格 |
| 页眉页脚混入正文 | 「第1页，共16页」夹在题目中间 |

**防**：**逐页对照原 PDF 校对**。这一步不能省，它是文本层流程的全部价值。

---

## §8 · 图片路径与引用

三条规则：

- 图片**必须**放在 `题库/<组别>/<年份>/assets/`
- `paper.md` 用**相对路径**引用：`![中文描述](assets/q015-fig1.png)`
- 替代文本必须是**中文描述**，不能是文件名

**症状**：校验报「图片引用指向的文件不存在」或「assets/ 中未被引用的孤儿图片」。

---

## §9 · 中间产物残留

`_pages/`（渲染的页面图）、`_tiles/`（切图块）都是中间产物，**交付前必须删**。

**任何下划线开头的目录都会被判为中间产物**（`validate.py` 会提示）。

> 曾经有一次审计代理在题库目录里留下 60 个 `_tiles/` 切图块，而当时的校验器只写死检查
> `_pages`，没拦住。现在改成通用规则了。

---

## §10 · 一道题挂两个标签

`topic:math`（上位）和 `topic:combinatorics`（下位）**不能同时挂**——
一道题被统计两次，题量和分值都会虚高。

**规则**：只挂最具体的那一个。排列组合题只标 `topic:combinatorics`。

筛选上位概念时，在页面上**同时选中下位标签**即可。

---

## §11 · 改了 meta.json 但页面读不到

答案和标签**两处都写**：`paper.md` 的题块注释 + `meta.json`。

页面**优先读 `paper.md` 的注释**，注释里没有才回退 `meta.json`。所以只改 meta 可能不生效。

**防**：改完跑同步工具，它会从 `meta.json` 往 `paper.md` 写：

```powershell
uv run python tools/tag_questions.py 题库/<组别>/<年份>
```

再跑 `--check` 确认同步。

---

## §12 · 结构逐年不同，不能推算

| 年份 | 总题数 | 阅读程序内部构成 |
|---|---|---|
| 2019 | 43 | 3 组 ×（4 判断 + 2 选择） |
| 2021 | 43 | (4+2)、(3+3)、(3+3) |
| 2024 | 42 | 合计 17 题，与前者都不同 |

**总量看着稳（阅读程序 40 分），内部切分却逐年变。**
任何「第 N 题一定是阅读程序第几组」的推断都会出错。**必须逐卷数。**

---

## §13 · 判断题没有选项

原卷的判断题只有「（ ）」，**没有 ABCD**。

- `paper.md` 里**不写选项**，题干照录，保留「（ ）」
- `answer` 填 `T`（正确）/ `F`（错误）
- 页面会自动补出「正确 √ / 错误 ×」两个可点项

**不要**自己在 `paper.md` 里造选项。

---

## §14 · 不要猜

看不清、拿不准、对不上——**一律标存疑，写进交付报告**。

题库是给教学用的，**错答案比没答案危害大**。

```markdown
## 存疑项
- p007 第 32 题选项 C 的符号模糊，疑似 `Θ(n log n)` 还是 `Θ(n²)`，按 n log n 记
- p012 代码第 18 行有涂改痕迹，按可辨认的 `++j` 记
```

R0 会裁决。在裁决之前，**不要自行订正原文**。

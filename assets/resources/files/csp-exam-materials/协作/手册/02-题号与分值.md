# 02 · 题号与分值

---

## 一、题号：全卷连续编号

**不沿用原卷的分节编号。** 按试卷物理顺序，给每一道**可计分的小题**依次编号，
从 `001` 开始，跨节不重置。

```
paper_id = csp-s1-<年份>[卷别]
qid      = <paper_id>-<三位序号>
```

例：`csp-s1-2019b-016`

### 为什么

1. **各年原卷编号方式不统一**：2019 在每组内按 `1) 2) 3)` 重新计数；2021 从 16 一路排到 43
2. **官方答案文件用连续编号**：2023 答案 43 个、2024 答案 42 个，都从 1 排到尾，可直接逐位对齐
3. **各年结构不同，序号无法推算**：

| 年份 | 总题数 | 阅读程序内部构成 |
|---|---|---|
| 2019 | 43 | 3 组 ×（4 判断 + 2 选择） |
| 2021 | 43 | (4+2)、(3+3)、(3+3) |
| 2024 | 42 | 合计 17 题，与前两者都不同 |

**总量看着稳（阅读程序 40 分），内部切分却逐年变。** 任何「第 N 题一定是阅读程序第几组」
的推断都会出错。**必须逐卷数。**

原卷编号保留在 `meta.json` 的 `original_no`（如 `"1"`、`"2)-3"`），用于回溯。

## 二、分值：显式标注优先，其余按节默认

原卷只对**部分**小题标了分值（如「（1 分）」「（3 分）」），其余沿用节内默认。

| 节 | 默认分值 |
|---|---|
| 一、单项选择题 | 每题 2 分 |
| 二、阅读程序 | 判断题 1.5 分，选择题 4 分 |
| 三、完善程序 | 每小题 3 分 |

**节声明里的默认值就在原文题头**，原样抄下来：

```markdown
## 二、阅读程序

> 程序输入不超过数组或字符串定义的范围；判断题正确填 √，错误填 ×；
> 除特殊说明外，判断题 1.5 分，选择题 4 分，共计 40 分。
```

### 同一节内分值可以不同

2019 阅读程序的实际分值：

```
判断题：1分、1分、1.5分、1.5分      ← 前两题有显式「（1 分）」
选择题：3分、4分                     ← 第一题有显式「（3 分）」
```

**不要按位置推。** 逐题读原卷标注，没有标注才用默认值。

### 用总分自检

三节分值上限是固定的：

```
一、单项选择题  30 分
二、阅读程序    40 分
三、完善程序    30 分
─────────────────────
合计           100 分
```

**把你标出的分值加总，必须等于 100。** 不等就说明某题分错了，回去查。

> 2019 的做法：显式标注 + 节默认 + 总分约束三者交叉验证，最终与官方答案表的分值列
> **逐题吻合**。这是个有效的自检手段。

## 三、写进哪里

| 位置 | 形式 |
|---|---|
| `paper.md` 题块注释 | `score: 2` |
| `meta.json` | `"score": 2` |

两处必须一致，`validate.py` 会查。

---

## 四、自检清单

- [ ] 题号从 001 起连续，无跳号
- [ ] 题号位数与 `qid` 末三位一致
- [ ] 每题分值来自显式标注或节默认
- [ ] 各节分值合计 = 30 / 40 / 30
- [ ] 总分 = 100
- [ ] `original_no` 已记录原卷编号

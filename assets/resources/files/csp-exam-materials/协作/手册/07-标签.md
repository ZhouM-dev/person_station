# 07 · 标签

每题挂两类内容标签，写在题块注释的 `tags:` 里：

```markdown
<!-- ... | tags: feat:lineref,feat:formula,topic:string -->
```

**逗号分隔，逗号后不加空格。** 词表见 [TAGS.md](../../TAGS.md)。

---

## 一、`feat:` —— 内容特征（自动推导）

描述题干里「有什么」，**机械可判**，由脚本从正文自动生成。

| 标签 | 中文名 | 判定条件 |
|---|---|---|
| `feat:figure` | 配图 | 题干有 `![...](assets/...)` |
| `feat:lineref` | 行号引用 | 题干出现「第 N 行」 |
| `feat:circnum` | 填空位 | 题干含 `①②③④⑤` |
| `feat:formula` | 公式 | 题干含 `$...$` |
| `feat:table` | 表格 | 题干有 Markdown 表格 |

**你不用手写这些**，跑一次工具就自动补齐：

```powershell
uv run python tools/tag_questions.py 题库/<组别>/<年份>
```

刻意不设 `feat:code`——一题是否需要读代码，`section`/`group` 已经说清楚了。
这五个标签描述的是**容易被工具弄坏的东西**：图会丢、行号会错、`①` 会被替换成 `(1)`、
公式会渲染坏。

---

## 二、`topic:` —— 知识主题（人工标注）

描述「考什么」，需要你判断。**一题可挂多个，但只挂最具体的那一个。**

| 标签 | 中文名 | 典型题 |
|---|---|---|
| `topic:basics` | 计算机基础与常识 | 文件格式、编译器功能 |
| `topic:lang` | 语言基础与语法 | 类型转换、运算符优先级 |
| `topic:math` | 初等数学与代数 | 数列、方程、不等式、几何 |
| `topic:combinatorics` | 组合计数 | 排列、组合、容斥、鸽巢、二项式 |
| `topic:number` | 进制与数论 | 二进制运算、取模 |
| `topic:bit` | 位运算 | 位压缩、异或 |
| `topic:ds` | 数据结构 | 并查集、栈、队列、哈希 |
| `topic:tree` | 树与二叉树 | 遍历、高度、笛卡尔树 |
| `topic:graph` | 图论 | 最短路、连通性、存图 |
| `topic:string` | 字符串 | 子序列、模式匹配 |
| `topic:sort` | 排序 | 稳定性、比较次数 |
| `topic:dp` | 动态规划 | 状态设计、转移方程 |
| `topic:greedy` | 贪心 | 贪心算法识别与证明 |
| `topic:search` | 搜索与回溯 | DFS、剪枝 |
| `topic:sim` | 模拟与枚举 | 按规则逐步模拟 |
| `topic:complexity` | 复杂度分析 | 时间/空间复杂度 |

### 只挂最具体的一个

排列组合题**只标** `topic:combinatorics`，**不再同时标** `topic:math`——
否则一道题被统计两次，题量与分值都会虚高。

| 上位标签 | 已拆出的下位标签 |
|---|---|
| `topic:math` | `topic:combinatorics`、`topic:number` |
| `topic:bit` 与 `topic:number` 相关但独立 | — |

筛选上位概念时在页面上**同时选中下位标签**即可。

### 词表锚定官方考纲

标签分类贴近 [《NOI 大纲（2025 年修订版）》](../../资料/NOI大纲-2025-考点.md)——
CCF 官方文件，也是 CSP-S（提高级）命题范围的权威依据。

| `topic:` | 考纲对应（提高级） |
|---|---|
| `topic:ds` | 2.2.3 数据结构 → 线性结构、哈希表 |
| `topic:tree` | 2.2.3 → 集合与森林、特殊树 |
| `topic:graph` | 2.2.3 → 常见图 |
| `topic:combinatorics` | 2.2.5 → 离散与组合数学 |
| `topic:number` | 2.2.5 → 初等数论 |

**拿不准某题该挂什么，去考纲里找它属于哪一节。**

---

## 三、⚠️ 不得自行新增标签

**这是硬规定。**

标签是**跨年份的全局维度**。各年各自扩展，会导致同一个知识点在不同年份挂不同标签，
题库就没法按知识点检索了。

### 需要新标签时

在 `协作/交付/<paper_id>.md` 里写：

```markdown
## 标签申请
- 拟新增：`topic:prob`（概率与期望）
- 理由：第 X 题考的是条件概率与贝叶斯公式，现有 16 个 topic 都覆盖不到
- 考纲依据：2.2.5 数学与其他 → 概率论（考纲里有，词表未单列）
```

R0 会更新 `TAGS.md` → 跑 `gen_tags.py` → 通知全体。

**在收到回复之前，该题先挂最接近的现有标签**，不要留空、不要用临时名字。

---

## 四、执行顺序

```
① 写 paper.md（先不管 tags）
② 写 meta.json 的 topic 标注
③ 跑 tag_questions.py  ← 自动补 feat，并从 meta 同步 topic 到 paper.md
④ 跑 validate.py       ← 词表、一致性检查
```

**`topic:` 只在 `meta.json` 里标**，`paper.md` 的注释由工具同步过去——
两边手改必然不同步。

---

## 五、自检

- [ ] 每题至少一个 `topic:` 标签
- [ ] 没有同时挂上位与下位标签
- [ ] 没有自造标签（跑 `validate.py` 会报「标签不在受控词表中」）
- [ ] `paper.md` 与 `meta.json` 的 tags 一致（跑 `tag_questions.py --check`）
- [ ] `tags.json` 与 `TAGS.md` 同步（跑 `gen_tags.py --check`）

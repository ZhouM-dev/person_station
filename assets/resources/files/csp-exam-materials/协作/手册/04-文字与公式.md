# 04 · 文字与公式

---

## 一、照录原则

**题干、选项保持原文措辞，不得改写、精简、补充。原文的错别字也照录。**

原文如果是错的（漏字、别字、表述不通），照抄。发现疑似错误，写进交付报告的
「存疑项」，由 R0 裁决——**不要自行订正**。

原文的空格、全角括号 `（）`、全角标点一律保留。

### 选项格式

- 统一写成 Markdown 无序列表，每项一行：`- A. 内容`
- 原卷选项同行排列（`A. 甲　B. 乙　C. 丙　D. 丁`）时，**一律拆成四行**
- 判断题不写选项，题干末尾保留原文的 `（ ）`

```markdown
- A. 0.000000
- B. 2.750000
- C. 3.500000
- D. 2.500000
```

## 二、数学公式

| 类型 | 写法 |
|---|---|
| 行内 | `$...$` |
| 行间 | `$$...$$`，单独成段 |

```markdown
第 $n$ 行的数为 $a_{n,1}, a_{n,2}, \ldots, a_{n,n}$。
```

**用标准 LaTeX 记号**，页面内置了转换器（`\le`→≤、`\log`→log、上下标、根式、分式），
不依赖外部库。认不出的命令会退化成去掉反斜杠的原文，不会变成乱码，但仍应尽量用
常见记号。

## 三、排版归一化（允许的转换）

以下属于**排版手段**，不改变任何字符内容，**允许并应当**统一：

| 原卷 | 转为 | 理由 |
|---|---|---|
| 中文引号包裹代码片段，如 `"<"`、`"fa[i] = 0;"` | 反引号 `` `<` ``、`` `fa[i] = 0;` `` | 引号是排版手段，不是题目内容 |
| 对代码标识符的加粗，如 **a[i]**、**status** | 行内代码 `` `a[i]` `` 或普通文本 | 同上 |
| 行内代码 | 反引号 | 统一 |

**除此之外的措辞一律照录，包括错别字。**

## 四、段落与缩进

原卷正文是**首行缩进两字**的中文排版。`paper.md` 里**不写缩进**——用空行分段即可，
页面渲染时会自动加首行缩进。你只要保证**段落切分正确**（原文另起一段的地方留空行）。

> **已知未还原项**：「提示：」等段落在原卷里是**整段缩进**（像引用块），
> 目前 `paper.md` 没有对应写法，尚未还原。遇到时**按普通段落写**，并在交付报告里
> 记一笔，不要自己发明标记。

## 五、代码块里的注释

原卷代码里的中文注释照录，位置不变：

```cpp
 13          pre[i] = j; // t[0..j-1]是s[0..i]的子序列
```

注释里的空格也照录（上面 `//` 后无空格就无空格）。

## 六、常见坑

| 症状 | 原因 | 处理 |
|---|---|---|
| 公式里的 `_` 或 `*` 被吃掉 | 转义顺序问题 | 用 `$...$` 包住整个公式 |
| 行内代码里的下划线消失 | 同上 | 用反引号包住 |
| 选项里的代码没进反引号 | 漏了 | 逐项检查 |
| 全角括号写成半角 | 手滑 | 照录原文，用全角 |
| 判断题写成「正确/错误」 | 原卷是「（ ）」 | 题干照录，选项由页面自动补 |

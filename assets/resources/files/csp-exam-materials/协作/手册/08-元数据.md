## 二、字段说明

### 试卷级

| 字段 | 必填 | 说明 |
|---|---|---|
| `paper_id` | 是 | `{exam小写}-{年份}{卷别小写}`，如 `csp-s1-2019b` |
| `title` | 是 | 与 `paper.md` 的 front matter **逐字一致**（校验器比对） |
| `exam` | 是 | `CSP-S1` 或 `CSP-J1`，**必须与组别目录名自洽** |
| `year` | 是 | 四位数字，**必须与年份目录名自洽** |
| `paper_variant` | 否 | 卷别 `A`/`B`；无卷别留空字符串 |
| `date` | 否 | `YYYY-MM-DD`，未知填 `null` |
| `duration_minutes` | 否 | 考试时长 |
| `total_score` | 是 | 满分，校验器会与各题分值加总比对 |
| `question_count` | 是 | 题目数，与 `questions` 数组长度一致 |
| `converted_at` | 是 | 转换日期 |
| `spec_version` | 是 | 当前 `1.5` |

### `groups[]`（顶层数组，v1.5 新增）

大题组的**组级程序说明**——「整段代码在求解什么」，属于组，不属于任何小题：

```json
{ "name": "阅读程序(1)", "section": "part2", "program_note": "……" }
```

| 字段 | 说明 |
|---|---|
| `name` | 组名，必须与 `questions[].group` **逐字一致**（校验器双向比对） |
| `section` | `part2` / `part3` |
| `program_note` | **必填、非空**。60~500 字，派生到该组 material 区的 `> **程序说明**` 块（见 [SPEC.md](../../SPEC.md) 3.9） |

- 第一节（单项选择题）没有组，`groups` 不出现或为空数组。
- **与答案无关**：没有答案源的卷也照样写。
- 每个组**恰好一个**；`paper.md` 里没有该块的组、或多了块的组，校验器都报错。

### `source`

| 字段 | 说明 |
|---|---|
| `file` | 源 PDF 相对仓库根的路径（权威位置在 `题目/`） |
| `copy` | 年份目录内副本的路径 |
| `sha256` | 源 PDF 的 SHA-256，**十六进制大写** |
| `pages` | 页数 |
| `kind` | `text`（原生文本层）/ `scanned`（扫描件） |
| `ocr` | 是否经过 OCR / 人工识读 |

**副本摘要必须与原件一致**——校验器会实际计算并比对。

### `sections`

```json
{ "id": "part1", "title": "一、单项选择题", "score": 30, "qids": [...] }
```

- `id`：`part1` / `part2` / `part3`
- `score`：该节分值合计，**校验器会与 `qids` 对应题目的分值加总比对**

### `questions[]`

| 字段 | 说明 |
|---|---|
| `qid` | 全卷连续编号 |
| `no` | 序号，与 `qid` 末三位一致 |
| `original_no` | 原卷编号，如 `"1"`、`"2)-3"` |
| `section` | `part1` / `part2` / `part3` |
| `group` | 大题组名，如 `"阅读程序(1)"`；第一节为 `null` |
| `type` | `single_choice` / `true_false` |
| `score` | 分值 |
| `images` | 图片文件名数组 |
| `tags` | 内容标签数组 |
| `answer` | `A`~`D` / `T` / `F` / `null` |
| `answer_note` | **题解的解释正文**。有 `answer` 的题**必填**（非空字符串）；`answer` 为 `null` 的题不写该字段 |
| `dispute_note` | **可选**：争议原因。只有争议题才写，其余题**不写该字段**（不是写空串） |

### `questions[].answer_note`（有答案的题必填）

写清「**为什么是这个答案、其它候选为什么不成立**」，它被解析成 `paper.md` 题解块的
`解释：` 行（见 [SPEC.md](../../SPEC.md) 3.9）：

- 字段位置紧跟 `answer` 之后，再之后才是 `dispute_note`。
- ⚠️ **语义在 v1.5 变更过**：v1.4 时它专指「存疑说明」，只给争议题写；
  **从 v1.5 起它是通用解释，有答案的题一律必填**。旧的「只给存疑题写」口径已作废。
- 多行用 `\n`；第一行接在 `解释：` 后面，其余行成为题解的续行。
- **文字规范见 [11-题解写作.md](11-题解写作.md)**：20~800 字、句末中文句末标点、
  不得含围栏代码块、不得出现内部协作用语。自检：
  `uv run python tools/lint_notes.py 题库/<组别>/<年份>`。
- 依据优先取 `协作/核验/<paper_id>.md`（有逐题实跑结论）；报告没覆盖的自己推导并
  **实际验算**（程序题真编译真运行，编译器 `C:\msys64\ucrt64\bin\g++.exe`）。
  **拿不准的不许编**——写能确认的部分，把不确定的追加进 `协作/待决/<paper_id>.md`。
- 程序输出、变量名用反引号；`$…$` 公式可用（同步工具会先剥离题解块再推导 `feat:` 标签，
  不会误加 `feat:formula`），但少给自己找麻烦。

### `questions[].dispute_note`（可选，只有争议题）

争议原因，派生到题解块的 `争议：` 行，**必须排在 `解释：` 之后**。
判据见 `协作/需求/02-题解标签.md` 附二 + v2 附则（与来源冲突 / 题面与答案不自洽 /
答案不唯一或答案源存疑）。写法要求：**先说与哪个来源冲突、对方给什么、本卷取什么、
依据是什么**（实跑的关键输入与输出、或量化实测），**不得只写「有争议」**。

**改完 `answer` / `answer_note` / `dispute_note` 或 `groups[].program_note` 必须重跑同步**：

```powershell
uv run python tools/tag_questions.py 题库/csp-s1/2021
uv run python tools/tag_questions.py 题库 --check
```

### `answer_source`

见 [06-答案处理.md](06-答案处理.md) §六。**无答案的年份也要写** `{"kind": "none"}`。

## 三、关键自洽关系

校验器**强制**以下关系，任何一条不满足都会报错：

```
组别目录名  ==  exam 的小写形式
年份目录名  ==  year
paper_id    ==  exam小写 + "-" + year + 卷别小写
title       ==  paper.md front matter 的 title
sections[].score  ==  该节题目分值加总
total_score       ==  所有题目分值加总
question_count    ==  questions 数组长度
no                ==  数组下标 + 1
qid               ==  paper_id + "-" + 三位补零的 no
source.sha256     ==  副本文件的实际摘要
source.copy 副本  ==  题目/ 里的原件
images            ==  paper.md 里引用的图片
answer_note       ==  paper.md 题解块里 `解释：` 行的内容（**有 answer 就必须非空**）
dispute_note      ==  paper.md 题解块里 `争议：` 行的内容（有无必须一致，且排在解释之后）
groups[].name     ==  questions[].group 的取值集合（双向：不多不少）
groups[].program_note == paper.md 该组 material 区里 `> **程序说明**` 块的内容
answer            ==  paper.md 题解块里 `答案：` 的值（判断题 T→√、F→×）
```

## 四、副本与摘要

年份目录里要放一份源 PDF 的**逐字节副本**，让目录自包含——单独拷给别人，
对方不看 `题目/` 也能核校转写。

```powershell
# 复制
Copy-Item "题目/2020-试题.pdf" "题库/csp-s1/2020/2020-试题.pdf"

# 算摘要
(Get-FileHash "题库/csp-s1/2020/2020-试题.pdf" -Algorithm SHA256).Hash
```

摘要填进 `source.sha256`（大写）。校验器会比对副本与原件是否一致。

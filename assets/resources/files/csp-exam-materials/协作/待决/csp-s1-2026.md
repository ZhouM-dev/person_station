  「每名学生还有一个预期得分 $x_i$。现在需要构造一份标准答案，使 ⟨此处⟩ 尽可能大。」
- **背景**：源 PDF **第 11 页**该行在**渲染图和文本层里都是空的**——

  也就是说第三方在把网页转 PDF 时把这一条行间公式弄丢了。
- **我的处理**：补成

  ```
  $$\sum_{i=1}^{n} |r_i - x_i|$$
  ```

  依据三条，都可复核：
  1. **同一页「提示」行里有同一个公式**，而且它是**完整的**——

  2. **洛谷讨论帖 `https://www.luogu.com.cn/discuss/1380094` 的 CSP-S OCR 题面**该处写着
     `使 \sum_{i=1}^{n}|r_i-x_i| 尽可能大。`——独立来源印证。
  3. 上下文语义闭合：空行的位置正好在「使」与「尽可能大。」之间，句式上只能放这个求和式。
- **需要你定**：

  cspfirstround（本卷源 PDF 第 14 页答案表）与洛谷主帖答案表都给 **C**（`39-43 CBDAA`）。
- **定案依据**（三条一致）：
  1. **实跑**：把四个候选分别填进 `c[i] = /* ① */;` 编译运行，用「枚举全部 2^m 份标准

     A 项 54/60 组不是最优、B 项 51/60、D 项 35/60，**只有 C 项 60/60 全对**；

  3. **两个独立来源**（cspfirstround、洛谷）给同一答案。

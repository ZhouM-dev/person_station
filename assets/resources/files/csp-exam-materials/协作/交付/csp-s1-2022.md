## 存疑项

### 1. 🟡 第 33 题：答案表与本卷程序实跑结果冲突（**需复核**）

- **位置**：`csp-s1-2022-033`
- **答案表**：`D`
- **本卷实跑**：输入 `1000000 19`，按卷面第 19、20 行
  （`ans[m++] = (n % (-k) + k) % k;` / `n = (ans[m - 1] - n) / k;`）编译运行，
  输出 **`87GIB`**，即本卷 **B** 项。手算复核一致：
  `1000000 = (87GIB)₋₁₉`。
- **D 项 `7CF1B` 是什么**：正是把第 20 行的 `/ k` 误写成 `/ (-k)`（k 误取负）后
  得到的典型错解 —— 说明 D 是命题时设计的**干扰项**，不是正确答案。
- **为什么判定答案表非本卷**：本卷可独立验算的 42 题，按**选项内容**回查本卷字母后
  与答案表**全部吻合**（含 `202`、`1401`、`91 37 46 98 26`、`O(nm)`、`10`、`计数排序`、
  `676000`、`(n-1)!/2`、`97`、`afedcb` 等唯一样本），不可能是「另一卷的选项重排」。
  故判定：该答案表就是本卷答案表，但第 33 题一格有误。
- **我的处理**：`answer` 取 **`B`**（按卷面程序实跑结果；手册 06 §三「独立验算是唯一能
  发现来源本身错了的手段」）。
- **需要你定**：确认取 `B`；若以官方答案表为准取 `D`，则需同时说明「按卷面程序实跑
  得 B」，否则会教错。

### 2. 🟢 第 13 题：原卷代码疑似有误（**照录未改**）

- **位置**：`csp-s1-2022-013`
- 卷面代码为 `for (j = 0; j < n; j*=2)`。`j` 初值 0 时 `j*=2` 恒为 0，内层是**死循环**，
  严格说该程序不会终止、时间复杂度无从谈起。
- 官方答案给 B（`O(n \log n)`），对应的是 `j` 初值为 1 的写法。
- **我的处理**：题干**照录原卷**（含 `j = 0`），未自行订正；答案取 **`B`**（B 项内容
  `O(n log n)` 即官方认定的答案；其余选项 `O(n)`、`O(n√n)`、`O(n²)` 均不符）。
- **需要你定**：是否在题库里加「原卷印刷有误」的注记（手册 04 不允许自行订正原文，
  故此处只标注、未改字）。

### 3. 🟢 第 11 题：`ℒ`/`𝒟` 的字形数与文本层码位数不一致（已按字形数照录）

- 文本层提取为 `ℒℒ` + 6 个 `U+1D49F`，但 600dpi 渲染肉眼可数出**只有 3 个 𝒟 字形**
  （「前 2 位字母 + 后 3 位数字」也印证是 2+3）。原因是该字体把每个数学字形编码成
  两个码位（全卷数学斜体皆然）。**按字形数照录为 `省A·ℒℒ𝒟𝒟𝒟`**，正文括注中的
  「两个 ℒ 和三个 𝒟」同步按单字形书写。

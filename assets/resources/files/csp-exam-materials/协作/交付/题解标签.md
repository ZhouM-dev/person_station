## 四、`answer_note` 的最终字段位置与 SPEC 字段表原文

### 位置

`meta.json` → `questions[]` 的每个题目对象，**紧跟 `answer` 之后**：

```json
    {
      "qid": "csp-s1-2019b-001",
      "no": 1,
      "original_no": "1",
      "section": "part1",
      "group": null,
      "type": "single_choice",
      "score": 2,
      "images": [],
      "tags": ["topic:lang"],
      "answer": "C",
      "answer_note": "仅存疑题写；说明为什么与来源冲突，见 4.1"
    }
```

无存疑的题**不写该字段**（不是写空串）。**2019 卷现在一个 `answer_note` 都没有**——
所以上面那个片段是 `SPEC.md` §4 的示例，不是 2019 的实况。

### `SPEC.md` §4 字段表原文（第 494 行）

```
| `questions[].answer_note` | **存疑题的解释**，可选（字符串）。紧跟 `answer` 之后；无存疑的题**不写该字段**（不是写空串）。多行用 `\n`；解析为 `paper.md` 题解块的 `解释：` 行，见 3.9 |
```

（原文一行，此处为可读性折行。）

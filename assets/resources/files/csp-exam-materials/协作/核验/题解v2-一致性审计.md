## 七、复核 R0 对 `csp-s1-2025` 第 43 行分号的处置

### 7.1 现状

`题库/csp-s1/2025/paper.md` 第 405 行（阅读程序(2) 的**代码第 43 行**）：

```
 43      for (int ti = w, nh = w;; --ti, nh += ti, nh = std::min(nh, n)) {
```

—— 印的是**双分号 `nh = w;;`**。`csp-s1-2025` 的 `meta.json` 里**已无** `-022` / `-027` 两条 `dispute_note`
（全卷争议只剩 `-016` / `-034` / `-035`），两条「卷面印漏一个分号」的争议**已撤**。

### 7.2 我的独立复核意见：**处置正确，而且双分号是唯一能自洽的写法**

1. **语法与语义上是必需的，不是多余字符。** `for (初始化; 条件; 步进)` 三段式里，
   `int ti = w, nh = w;` 是初始化语句，第二个 `;` 是**空条件**（循环靠函数体内的 `return` 退出），
   `--ti, nh += ti, nh = std::min(nh, n)` 是步进部分。
   若只有一个分号，语句会变成 `for (int ti = w, nh = w; --ti, nh += ti, nh = std::min(nh, n))`——
   步进段消失、逗号表达式变成循环条件（其值为 `nh ≠ 0`）→ 循环结构与 `guess2` 的「跳跃步长逐次减一」完全不符。
   **所以「少一个分号」不是排版瑕疵，而是会改变程序行为的错误。**
2. **两个独立来源都说 `;;`**：① 原卷内嵌内容图 1080 px 放大 5 倍（同页第 41 行只有一个分号，字形可对照）；
   ② 第三方题目文本层（机器抽取）。R0 独立核对原件得到同一结论。
3. **与核验结论自洽**：`协作/核验/csp-s1-2025.md` 的实跑（第 22 题 `6 5 1`→5 次、`6 5 2`→3 次；
   第 27 题 n=100、t=2 最大 14）只有在**双分号**的代码上才成立；争议原文自己也写了
   「按看得见的一个分号理解会得 2 次 / 13 次」——**这正是「转写掉了分号」的直接后果，而不是卷面缺陷**。
4. **撤争议是对的**：修完 `paper.md` 后，「卷面（＝我们的 `paper.md`）」与「第三方来源」在这一点上**不再有分歧**，
   争议的前提消失。保留反而会让学员以为真题印错了。**两条一起撤、且撤得干净（meta 与 paper 都无残留），处置完整。**

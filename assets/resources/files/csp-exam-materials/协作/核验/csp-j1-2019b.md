### 4.1 完善程序(1)「矩阵变幻」（q034–q038）

题面要求：n=1 输出 `00 / 01`；n=2 输出 `0000 / 0101 / 0011 / 0110`（即原卷那个 4×4 矩阵）。

```

  B1 = 'n % 2'      -> 正确=False  n=1:'00\n00\n'
  B1 = 't'          -> 正确=True   n=1:'00\n01\n'; n=2:'0000\n0101\n0011\n0110\n'   <== 正确
  B1 = '0'          -> 正确=False  n=1:'00\n00\n'
  B2 = 'x - step, y'        -> 正确=False（空输出/越界）
  B2 = 'x, y - step'        -> 正确=False  n=2:'0000\n0001\n0101\n0110\n'
  B2 = 'x - step, y - step' -> 正确=False（空输出/越界）
  B2 = 'x, y'               -> 正确=True   <== 正确
  B3 = 'x + step, y + step' -> 正确=True   <== 正确
  B3 = 'x, y - step'        -> 正确=False
  B3 = 'x - step, y'        -> 正确=False（空输出/越界）
  B3 = 'x - step, y - step' -> 正确=False（空输出/越界）
  B4 = 'n - 1, 0'           -> 正确=False
  B4 = 'n - 1, n % 2'       -> 正确=False
  B4 = 'n, 0'               -> 正确=True   <== 正确
  B4 = 'n, n % 2'           -> 正确=False
  B5 = 'n + 1'              -> 正确=False
  B5 = '1 << n'             -> 正确=True   <== 正确
  B5 = '1 << (n - 1)'       -> 正确=False
  B5 = '1 << (n + 1)'       -> 正确=False
```

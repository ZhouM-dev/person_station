## 二、不属实清单（6 处）

### 1. `csp-j1-2020-041` —— 选项判读自相矛盾 ★中度

- **解释原文**：「B 项与 D 项**比较的对象对**、符号反了；C 项比的是 `A[i - 1]`，那是刚刚
  可能已被丢掉的位置，不是「最后一个保留的区间」……」
- **实际是什么**：`paper.md` 该题四个选项逐字为
  A. `A[i].b > A[p - 1].b` / B. `A[i].b < A[i - 1].b` / C. `A[i].b > A[i - 1].b` /
  D. `A[i].b < A[p - 1].b`。
  **B 项比较的对象是 `A[i - 1]`**，与 C 项完全相同（差别只在符号），
  也就是说同一句话里「B 的对象对」与「C 的对象错」互相矛盾。
  B 的正确说法应是「**对象与符号都错**」。
- **依据**：`uv run python` 抽取该题 `paper.md` 选项原文（见 §三·2 的脚本输出，B/C 两项
  只差一个不等号）。
- **严重程度**：**中度**。不影响答案（A 仍是唯一正确项），但会误导学员对两个干扰项的
  理解——正是「解释比没有解释危害更大」的那类。

### 2. `csp-j1-2020-029` —— 把 DP 结果说成「实跑」

- **解释原文**：「实跑 n = 20、全 0 输入输出 `0`。」
- **实际是什么**：该程序是 `(n−1)!` 条分支的暴搜，n = 20 是 19! ≈ 1.2×10¹⁷ 次递归，
  **不可能实跑**。我实测：n = 8、10、11、12、13 都能返回（0），**n = 14 起 25 秒不返回**
  （超时）。核验报告写的是 `Q029 (n=20 all zero) -> interval DP = 0`，真程序只跑到 n = 8。
- **依据**：
  ```
  n=8 -> '0' rc=0 ; n=12 -> '0' rc=0 ; n=13 -> '0' rc=0
  n=14 -> TIMEOUT(25s) ; n=16 -> TIMEOUT(25s) ; n=20 -> TIMEOUT(25s)
  ```
- **严重程度**：中低。结论（输出 0）正确且另有 n = 8 的实跑与区间 DP 支撑，但「实跑 n = 20」
  这句**不可复核**，属证据口径不实。

### 3. `csp-j1-2020-035` —— 干扰项的现象说错（卡死 vs 崩溃）

- **解释原文**：「A 项 `n / i` 与 B 项 `n / (i * i)` …… **（实跑卡死）**」
- **实际是什么**：A 项确实卡死（超时）；**B 项是崩溃**：i 涨到 65536 时 `i * i` 在 int 里
  溢出为 0，触发整数除零，进程立刻以 `0xC0000094`（3221225620）退出，并非「卡死」。
- **依据**：变体程序实跑 → `B 项 n=120 -> '' rc=3221225620`（A 项 `TIMEOUT(5s)`）。
- **严重程度**：轻度。不影响答案 B。

### 4. `csp-j1-2021-018` —— 中间逐项枚举错位

- **解释原文**：「5 = 101 有 2 个 1……输出 3；2 = 10 输出 1 + 2 = 3；11 = 1011……输出 4；
  9 = 1001 输出 2 + 1 = 3；16 = 10000 输出 1 + 16 = 17。实跑该输入得到 `3 4 3 17 4`……」
- **实际是什么**：题面输入是 `5 2 11 9 16 10`（**第一个 5 是 n，不是数据**），真正的数据是
  2、11、9、16、**10**。所以列举应是 `3、4、3、17、4`，而不是文中的 `3、3、4、3、17`。
  该条**末句与结论正确**：实跑确实得到 `3 4 3 17 4`，题面写 `3 4 3 17 5`，故填 ×。
- **依据**：`echo 5 2 11 9 16 10 | 程序` → `3 4 3 17 4`（与解释末句一致）。
- **严重程度**：中低。学员照中间那串自己复算会对不上题面。

### 5. `csp-j1-2025-043` —— 括号里的错例数（6204）对 `count` 这一项不成立

- **解释原文**：「……B 项 `count` 是票数、不是人的编号，可能为 0 或其它值；D 项固定输出 0，
  等于没做任何消除。把这三项代进去实跑，在 18242 种情形里**各自都会印出糊涂人
  （错 6204 种）**。」
- **实际是什么**：我按报告 §3.6 的口径独立重建了对抗穷举模型（见 §三·4），复现出
  总情形 **18242**、总模拟 **18679808**、本库组合错 **0**、第三方组合错 **9940**、
  ①=A 错 **580**、③=&& 错 **3528**——与报告逐项吻合，说明模型一致。在同一个模型上：
  ⑤=A（`N-1`）= **6204** ✓、⑤=D（`0`）= **6204** ✓、**⑤=B（`count`）= 6018 ✗**。
- **依据**：自写 `j1_2025_c2enum.exe`（N ≤ 6 全量枚举）输出
  `q043 5=A(N-1) = 6204 / 5=B(count) = 6018 / 5=D(0) = 6204`。
- **严重程度**：轻度。答案 C 与理由不受影响，只是括号里的统计数字对 B 项偏高 186。

### 6. `csp-j1-2019b-030` —— 「都小了至少一个数量级」措辞夸大

- **解释原文**：「A 项 6、B 项 100、D 项 600 都小了**至少一个数量级**。」
- **实际是什么**：正确值 5050，D 项 600 与它的比是 **8.4 倍**，不到 10 倍（一个数量级）。
  A 项 6、B 项 100 确实差一个数量级以上，D 项不满足。
- **依据**：5050 ÷ 600 = 8.42。
- **严重程度**：轻度（措辞，不影响答案 C）。

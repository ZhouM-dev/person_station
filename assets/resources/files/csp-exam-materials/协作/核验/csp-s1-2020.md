### 4.3 判为「存疑」的那一处：Q1「最大」

- **目视**：1200 dpi 放大到「以下最大的数（ ）」，`最`/`大` 与 `以`/`下`/`的`/`数` **同重**。
  作为对照，p003 Q16 的「必须」「可能」在 700 dpi 下**一眼可辨**地重于同行的「否则程序」，
  p001 Q5 的「不会」在 400 dpi 下同样一眼可辨。**「最大」没有这个效果。**
- **测量**（900 dpi，逐字笔画粗，单位 px）：`请`13.4 `选`12.0 `出`11.3 `以`15.6 `下`13.4
  **`最`12.6** **`大`20.6** `的`13.4 `数`15.6。
  → 若「最大」整体加粗，`最` 不应落在常规档（12.6，反而低于「请」「以」「数」）。
  `大` 偏高是**字形伪影**：「大」的撇捺在宋体里本就粗、且交点多，distance-transform 峰值被抬高。
- **判定**：**疑似误标（存疑）**。建议 R0 裁决：如认可，删去这一处 `**`；
  如认为原卷确有此意，请保留并在手册里注明依据。

## 五、`Θ` / `θ` 大小写核对（**本报告最硬的一条**）

### 结论

**Q30 转写错误**。原卷是小写 `θ`，`paper.md` 写成了大写 `\Theta`。

### 字形取证

三个符号按同一比例（1200 dpi，等高缩放）并排比对：

| 位置 | 原卷字形 | 形态 |
|---|---|---|
| p002 Q7 选项 A | `Θ(n+e)` | **宽圆**的 O 形，中横**短且悬空**、两端不接壁 → **大写 Θ** |
| p005 Q24 选项 A | `θ(n log n)` | **窄长**椭圆，中横**贯通全宽并向右探出** → **小写 θ** |
| p008 Q30 | `θ(n!)` | **与 p005 完全同形**（窄长 + 贯通长横） → **小写 θ** |

三者的 w/h 比：p002 **0.733**（宽圆）｜p005 **0.656**｜p008 **0.595**（窄长）。
p008 与 p002 相差 19%，与 p005 仅差 10%——**p008 属于小写一档**。

```

```

**应为 `$\theta(n!)$`。**

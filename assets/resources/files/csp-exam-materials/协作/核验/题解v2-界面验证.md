## 一、怎么导入数据、怎么驱动浏览器（可复现）

手法照抄仓库里现成的 `tools/test_page.py`（那是用户认可的做法）：

1. `viewer.html` 是纯静态单文件（无外链 JS/CSS），用 `file:///F:/ai/试题/viewer.html` 直接打开。
2. 页面提供全局 `ingest(entries)`，`entries` 形如 `{file, rel}`，`rel` 决定试卷归属目录。
   用 `new File([content], name, {type})` 造文件、`Object.defineProperty(f, "webkitRelativePath", {value: rel})`
   伪造相对路径，即可**绕开真实文件选择器**把题库塞进页面：

   ```js
   (papers) => {
     const mk = (name, rel, body, type) => {
       const f = new File([body], name, { type });
       Object.defineProperty(f, "webkitRelativePath", { value: rel });
       return f;
     };
     const bin = s => Uint8Array.from(atob(s), c => c.charCodeAt(0));
     const out = [];
     for (const p of papers){
       out.push({ file: mk("paper.md",  p.dir + "/paper.md",  p.md,   "text/markdown"), rel: p.dir + "/paper.md" });
       out.push({ file: mk("meta.json", p.dir + "/meta.json", p.meta, "application/json"), rel: p.dir + "/meta.json" });
       for (const a of p.assets)
         out.push({ file: mk(a.name, p.dir + "/assets/" + a.name, bin(a.b64), a.type),
                    rel: p.dir + "/assets/" + a.name });
     }
     ingest(out);
   }
   ```
   `paper.md` / `meta.json` 按 UTF-8 读成字符串；`assets/*.png` base64 内联。**PDF 不必给**
   （只影响「对比查看」页，与本次核验无关；页面会显示「—」）。
3. 驱动：`uv run --with playwright python <脚本>`，`p.chromium.launch(channel="chrome")` 用**真实 Chrome**，
   `viewport=1440x950`。等 `[data-ui="qcard"]` 出现即注入完成。
4. 两种注入口径：
   - **全 14 卷一次注入** → 做总数普查、题干污染扫描、结构/样式指纹对比；
   - **每卷单独注入（每次新开一页）** → 做逐项判定。
     这一点很关键：把 14 卷一起注入后 `document.querySelector('.soldisp')` 只会拿到**全局第一个**，
     按卷比样式会变成"自己跟自己比"。本报告所有按卷结论都来自「一卷一页」。
5. 命令前缀（`uv` 不在 PATH）：
   ```
   set "PATH=C:\Users\Administrator\.cherrystudio\bin;%PATH%" && chcp 65001 >nul && set PYTHONIOENCODING=utf-8 && uv run --with playwright python <脚本>
   ```
6. 核验脚本写在 `%TEMP%`（仓库只读，脚本不入库）：`r2_verify.py`（census/focus 两段）、
   `r2_extra.py`、`r2_extra2.py`、`r2_extra3.py`、`r2_extra4.py`、`r2_shots.py`、`r2_shots2.py`；
   中间结果 `%TEMP%/r2_result.json`、`r2_extra*.json`、`r2_per_paper.json`、`r2_struct.json`。
   `browser-use` 技能在子代理里报 `Browser is not available in subagent`，所以全程用 Playwright。

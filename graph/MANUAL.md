# Graph Studio · 功能手册

> 图数据可视化工具 · 轻量、直观、无需后端。
> 本手册覆盖两个版本：**桌面版 `index.html`** 与**移动版 `mobile.html`**。
> 更新日期：2026-08-17

---

## 一、版本与入口

| 版本 | 文件 | 适用场景 |
|---|---|---|
| 桌面版 | `index.html` | 桌面浏览器、鼠标 + 键盘操作 |
| 移动版 | `mobile.html` | 手机 / 平板 / 触控笔设备 |

**入口逻辑**：打开 `index.html` 时，若检测到移动设备或窗口宽度 < 768px，会自动跳转到 `mobile.html`。移动版也可作为单文件独立部署。

**返回主页**：两个版本左侧栏底部的「返回主页」按钮（房子图标 + 文字），点击回到个人主页 `https://zhoum-dev.github.io/person_station/`。

## 二、快速开始

1. 在左侧「输入图数据」文本框中粘贴或输入边数据，停止输入约 0.5 秒后自动绘制。
2. 数据格式：
   - 每行一条边：`起点 终点 [权重]`，例如 `1 2 4`
   - 点权：`节点:权重`，例如 `1:5`（节点权重，显示在节点下方）
   - 点权行：首行声明 `节点数 边数` 时，第二行若有「节点数」个数值，视为点权行（按节点编号顺序），第三行起为边
   - 首行可为 `节点数 边数` 声明
   - 单独一列表示散点
   - `#` 或 `//` 开头的行视为注释，被忽略
3. 点击「载入示例」可加载示例数据快速体验。
4. 点击「随机 · 生成」可随机生成普通图或树。

## 三、模式（核心工具栏）

顶部工具栏从左到右共 5 种模式：

| 模式 | 快捷键 | 功能 |
|---|---|---|
| 触摸 | `V` | 拖拽节点和画布；停留后拖动框选；单击边可多选；Ctrl/Command + 单击节点多选 |
| 绘制 | `D` | 短按节点连线；长按节点移动；点击空白建点；拖动空白平移 |
| 删除 | `X` | 点击节点、边或画布笔迹即可删除 |
| 画布 | `P` | 进入涂画模式，配合下方的画笔工具使用 |
| 圈选 | `Q` | 自由圈住笔迹后整体移动、复制、粘贴 |

> 切换模式会显示对应操作提示在画布底部状态栏。

---

## 四、画布工具（画布模式下的子工具）

进入「画布」模式后，模式栏右侧展开画笔工具区：

| 工具 | 快捷键 | 说明 |
|---|---|---|
| 画笔 | `B` | 自由涂画（颜色可设） |
| 直线 | `L` | 绘制直线 |
| 箭头 | `A` | 绘制箭头 |
| 文本 | `T` | 插入文本，可拖动右下角调整字号 |
| 表格 | `G` | 拖拽绘制表格（详见下节） |

- **颜色**：点击色环选择 6 种基础色，或「更多」自定义颜色；每种工具独立记忆颜色。
- **清除按钮**：任何模式下始终显示。单击清除画布上的笔迹 / 文本 / 表格（保留图形），420ms 内双击清除全部内容。

## 五、表格功能

### 设置项（表格面板）
- **单元格宽**：40–240px，默认 80px
- **单元格高**：24–160px，默认 40px
- **字体大小**：8–40px，默认 12px

### 绘制方式
1. 在「画布」模式下选择「表格」工具。
2. 在画布上**拖拽**出一个矩形区域，拖拽过程中**实时预览**表格网格（外框 + 网格线随单元格宽高划分）。
3. 松手后自动生成表格：`列数 = round(拖拽宽 ÷ 单元格宽)`，`行数 = round(拖拽高 ÷ 单元格高)`，最小 1×1。
4. 表格尺寸自动对齐为单元格宽高的整数倍。

### 编辑表格
- 点击单元格直接输入内容。
- 拖动表格整体移动。
- 停留片刻再拖动可**框选**多个单元格。
- `Ctrl+Enter`：对选中区域**递增 / 复制填充**。
- 「删除」模式下点击表格可删除整个表格。

### 修改字号
- 新建表格时按面板「字体大小」生效。
- 编辑已有表格时（点击单元格进入编辑后）调整「字体大小」输入，立即应用到当前表格。

## 六、其它操作与快捷键

| 操作 | 快捷键 |
|---|---|
| 撤销 / 恢复 | `Ctrl+Z` / `Ctrl+Y`（或工具栏按钮） |
| 整理图形（树按层级，图自动调整） | `R` |
| 退出编辑，返回触摸模式 | `Esc` |
| 复制笔迹 | `Alt + 拖动` |
| 复制 / 粘贴圈选笔迹 | `Ctrl+C` / `Ctrl+V` |
| 临时箭头 | `Ctrl + 左键拖动` |
| 表格填充 | `Ctrl+Enter` |
| 触控笔临时删除（移动版） | 按住 `PgDn`，松开返回 |

### 顶部工具栏
- 撤销 / 恢复
- 主题切换（深色 / 浅色，界面与画布同步）
- 随机生成（普通图 / 树，可设节点数）
- 缩放（＋ / −）与「适应画布」

### 左侧设置面板
- **有向图**：为边显示方向箭头
- **显示权重**：显示每条边的第三列
- **显示点权**：显示节点冒号后的数值（节点下方小字）
- **布局整理**：设置树根；「图」执行一次整理，「树」切换自动整理

## 七、两个版本的差异

| 项目 | 桌面版 `index.html` | 移动版 `mobile.html` |
|---|---|---|
| 部署入口 | 桌面浏览器；窄屏自动跳转移动版 | 移动 / 触控设备；单文件独立部署 |
| 侧栏位置 | 左侧 | **右侧**（单文件移动版镜像布局） |
| 窄屏表现 | 侧栏折叠成窄条快捷按钮 | 侧栏变为**抽屉式浮层** |
| 交互方式 | 鼠标 + 键盘快捷键 | 触控笔 / 手指 + 手势 |
| 双指缩放 / 平移 | 鼠标滚轮缩放 | 支持触控手势 |
| 仅触控笔绘制 | 无此选项 | 有；开启后手指只平移缩放，触控笔才绘制 |
| 触控笔临时删除 | 无 | 按住 `PgDn` 临时进入删除，松开返回 |
| 节点多选 | Ctrl/Command + 单击 | 单击 / 重复单击切换 |
| 表格单元格样式 | 内边距 3×5、边框 2px | 内边距 1×2、边框 1px（适配小屏） |
| 表格默认尺寸 | 宽 80 · 高 40 · 字号 12 | 首次使用无设置时单元格取最小值 |
| 工作区状态 | 设置本地保存 | 设置 + **画布视图状态**额外保存 |

**共同点**：数据格式、五种模式、画布工具、表格绘制与编辑、撤销 / 恢复、主题切换、随机生成等核心功能完全一致。

## 八、数据格式速查

```
# 有向带权图（首行声明节点数与边数）
4 4
1 2 5
2 3 3
3 4 8
4 1 2

# 普通图（每行一条边）
1 2
2 3
3 1

# 散点（单独一列）
1.5 2.0
2.0 3.5
3.5 1.0

# 点权（节点:权重，单独一列；冒号后为节点权重）
1:5
2:3
1 2

# 点权行（首行 n m，第二行 n 个点权，第三行起为边）
3 2
5 8 3
1 2
2 3
```
